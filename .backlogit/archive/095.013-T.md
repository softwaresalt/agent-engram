Add the assignment-and-scope EVENT EMISSION half of the Python lineage path in the spark_lineage submodule, split out of U2 per H4's 2-hour granularity rule; CONSUMES U2a's (095.003-T) call-level resolved LineageEndpoint + receiver/order/scope data (the seam); U2c does NOT consume or produce LineageEdgeCandidate (candidates are U2b's downstream join). Expose the PUBLIC entry point spark_lineage::extract_python_lineage(source, authority_ctx) -> Vec<SparkLineageEvent> that tests call DIRECTLY — do NOT route lineage through parse_source, which returns ParseResult { symbols, edges } and has NO lineage carrier (PR #281 finding 3). Walk the AST and emit the SHARED U2->U2b contract type SparkLineageEvent — a TAGGED EVENT with THREE kinds, each carrying source-order index + enclosing scope (top-level cell/module body vs a branch / loop / nested / comprehension / with / except / def / class block): (1) an atomic READ BIND event — a resolved Spark read assignment (df = spark.read...(literal) / spark.table(literal)) is modeled as ONE Bind (the U2a-resolved LineageEndpoint + the receiver variable name), NOT a read-call PLUS a separate rebind at equal source-order, so it does NOT self-invalidate (AR-02); (2) a WRITE CALL event (the U2a-resolved LineageEndpoint or an unresolved marker + the receiver = the base simple-name at the CHAIN ROOT — AR-13); (3) a NON-SPARK (RE)BINDING / INVALIDATION event emitted for ANY assignment/binding form whose left side is a tracked name with a NON-Spark RHS (df = other, df = compute()) — cycle-5 finding F2 — where spark itself is ALSO a tracked name so spark = other invalidates (AR-29). The rebind event lets U2b invalidate a prior df->dataset binding and fail closed at a later df.write: a resolver seeing only whitelisted Spark-call events could NOT detect df = other and would emit a FALSE edge (extends the cycle-4 finding E2 event model). SCOPE RULE (AR-07): new bindings AND writes are honored ONLY for statements that are DIRECT CHILDREN of the module/cell body; a rebind of a tracked name in ANY other scope/form — branch, loop, nested, comprehension, with/except target, del, augmented-assign, walrus, import, def/class — INVALIDATES the binding (never silently dropped); tighten the scope enum to record which form each event came from. Tests: an atomic-bind sequence df = spark.read("in"); df.write("out") emits exactly ONE read Bind (receiver df) + ONE write event and NO self-invalidation (AR-02); a mode-chain write df.write.mode("overwrite").saveAsTable("c.s.t") emits a write event whose receiver is the chain-root simple-name df (AR-13); a tracked-name rebind in EACH scope/form — branch, loop, comprehension, with/except target, del, augmented-assign, walrus, import, def/class — emits an INVALIDATION event, AND spark = other invalidates (per-form rejection tests, AR-07/29). Granularity: 4 functions, 3 test scenarios — within the 2-hour gate. Domain: python-parser (width-isolated). Blocked by U2a (095.003-T). Event consumer: U2b (095.004-T). Plan Unit 2c.
