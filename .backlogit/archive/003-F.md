## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Right now, the code-graph folder is at the root of the .engram directory, but it should be part of the db/branch-version directory so that vector and graph stores are together under db and feature together.
<!-- SECTION:DESCRIPTION:END -->

## Resolution

<!-- SECTION:RESOLUTION:BEGIN -->
Closed as resolved by Schema 4.0.0 (`src/services/dehydration.rs` line 66). The current layout is an intentional design decision rather than an oversight:

- `.engram/code-graph/{branch}/` — Git-tracked serialised code graph (travels with the repo)
- `.engram/db/{branch}/` — Git-ignored embedded DB files (machine-local, regenerated on demand)

Co-locating tracked and untracked artefacts under the same directory would place Git-tracked files inside a `.gitignore`-covered path, making them invisible to version control. The separation preserves both branch-awareness (the original goal) and the tracked/untracked boundary. No further work is needed.
<!-- SECTION:RESOLUTION:END -->
