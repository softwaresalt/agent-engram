## Improved Class resolution heuristics

## Description

Extend `resolve_reference_target` (from 035.003-T) with additional matching
heuristics for SQL identifiers:

1. Strip surrounding SQL quotes (`"Users"` → `Users`, `[dbo]` → `dbo`)
2. Case-insensitive fallback via `get_class_by_name_ci` using
   `string::lowercase(name) = string::lowercase($name)`

This reduces the number of references that fall through to self-loop when the
target Class exists but with different casing or quoting.

## Scope

- `src/db/queries.rs` — add `get_class_by_name_ci` method, extend
  `resolve_reference_target` with quote-stripping and CI fallback
- `tests/contract/references_edge_test.rs` — contract tests for CI resolution
  and quoted identifier resolution

## Acceptance Criteria

- `resolve_reference_target("users")` resolves when Class named `Users` exists
- `resolve_reference_target(r#""Users""#)` strips quotes and resolves
- `resolve_reference_target("USERS")` resolves via case-insensitive fallback
- `resolve_reference_target("nonexistent")` still returns None
- Contract test with case-mismatch self-loop verifies resolution after reresolve
- `cargo test` and `cargo clippy` pass

## Execution Posture

Test-first: write failing contract test for case-insensitive resolution (red),
implement heuristics (green).
