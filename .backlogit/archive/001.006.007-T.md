The bfs_impl implementation uses a Rust-side BFS loop rather than a native Datalog fixpoint query. A Datalog-native BFS would reduce round-trip overhead for deep traversals. Source: docs/closure/2026-04-30-014-s-cozodb-phase3-4-closure.md

## Status: DEFERRED

Deferred per deliberation (docs/decisions/2026-05-01-cozodb-phase5-7-deliberation.md). Rust-side BFS is correct, tested, and performant at current scale (≤750 lightweight in-process queries). Easier to optimize after single-backend state when there's only one implementation to maintain.
