Wire the `--direct` flag and `ENGRAM_DIRECT` env var into the `Sync` and `Index` CLI subcommands.

## Implementation

1. Add `--direct` flag to `Sync` and `Index` variants in `src/bin/engram.rs`
2. Add `ENGRAM_DIRECT` env var check: if set to `1`/`true`, behave as if `--direct` was passed
3. In the match arms for `Sync` and `Index`, dispatch to `direct::run_direct()` when `--direct` is active, otherwise use existing `run_tool()` path
4. Update `--help` text for both subcommands to document the new flag

## Acceptance Criteria

- `engram sync --direct` routes through `direct::run_direct()`
- `engram sync` (no flag) routes through existing `run_tool()` path
- `engram index --direct` routes through `direct::run_direct()`
- `ENGRAM_DIRECT=1 engram sync` behaves like `engram sync --direct`
- Explicit `--direct` flag takes precedence over env var absence
- `cargo test` passes
- `cargo clippy -- -D warnings -D clippy::pedantic` clean

## Scope

- `src/bin/engram.rs` — add `direct` field to `Sync` and `Index` variants
- `src/cli/commands/indexing.rs` — add `direct` parameter to `run_sync()` and `run_index()`
