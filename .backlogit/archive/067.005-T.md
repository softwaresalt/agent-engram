NEW (Amendment 1, 2026-07-03). Add the caller-supplied correlation id to the engram CLI and thread it to the daemon emit choke point. Width: cli/ipc.

Scope:
- src/cli/flags.rs (GlobalFlags): add `correlation_id: Option<String>` as `#[arg(long, global = true, env = "ENGRAM_CORRELATION_ID")]`, mirroring `--workspace`. Precedence: explicit flag > env > unset.
- src/cli/runner.rs (run_tool_timed): when set, merge a sanitized `_meta.correlation_id` into the request params (create `_meta` if absent) BEFORE building IpcRequest. Single central injection site — no per-command builder churn (`&flags` already threaded). The daemon extracts it at src/tools/mod.rs::dispatch via extract_correlation_id (067.002-T).

This is a CLI-surface (clap) addition only — NO MCP per-tool input-schema change (`_meta.correlation_id` is envelope-level). Emitting subcommands: search/query-memory/symbols/map-code/impact/query-graph/sync/index/bind + report/stats/health/branch-metrics/workspace-status/daemon-status; inert on install/uninstall/manifest/verify.

Tests (unit, ≤4): (1) flag parses + env fallback + flag-overrides-env; (2) injection adds _meta.correlation_id when no _meta present; (3) injection preserves existing _meta.agent_role; (4) unset → params unchanged.

Depends on 067.002-T (daemon must extract what the CLI injects for a coherent increment).
