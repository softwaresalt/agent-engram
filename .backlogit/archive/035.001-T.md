## Add INDEX on target field in references schema

## Description

Add `DEFINE INDEX IF NOT EXISTS references_target ON TABLE \`references\` COLUMNS target`
to the `DEFINE_CODE_EDGES` constant in `src/db/schema.rs`. This enables efficient queries
on the `target` column, particularly for the `WHERE target = source` predicate in
`reresolve_references_edges`.

## Scope

- `src/db/schema.rs` — add index definition after existing `references_source` index
- `tests/contract/references_edge_test.rs` — add assertion that index exists via
  `INFO FOR TABLE \`references\``

## Acceptance Criteria

- `DEFINE INDEX IF NOT EXISTS references_target` present in schema definition
- Contract test verifies index exists after schema creation
- `cargo test` passes
- Index is idempotent (IF NOT EXISTS) — safe for existing databases

## Execution Posture

Test-first: write index-existence assertion (red), add index definition (green).
