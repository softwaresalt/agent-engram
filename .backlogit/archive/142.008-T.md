Plan unit F04a - IPC server seam extraction and module decomposition. `src/daemon/ipc_server.rs` is 2,452 lines and was co-owned by five units; the Revision 6 operator decision was to decompose rather than lengthen the serialization chain.

Perform a behavior-preserving mechanical extraction into four new modules - `startup_activation.rs`, `request_entry.rs`, `error_transport.rs`, `lifecycle_policy.rs` - each shipping a pass-through implementation that carries today's semantics. Declare every seam signature up front so no downstream unit ever edits the seam file to wire itself in. Reduce `ipc_server.rs` to a composition root: framing, the accept loop, and delegation to the four seam points.

Execution posture: characterization-first mechanical move. The tree must be GREEN at extraction with no behavior change bundled in.
