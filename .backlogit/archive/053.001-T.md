title: Surface indexing progress events from long-running index workflows
updated_at: 2026-05-14T19:59:05.5013151-07:00

Expose progress or lifecycle events from indexing execution paths so long-running index operations can report useful status upstream.

<!-- BEGIN:acceptance-criteria -->
- Indexing workflows emit progress or lifecycle state changes consumable by the CLI
- Exact totals are optional, but user-visible progress must still be meaningful
- Scope stays on progress event generation rather than terminal rendering
<!-- END:acceptance-criteria -->

<!-- BEGIN:implementation-notes -->
Supports both `engram index` and `engram sync --full` without expanding into telemetry analytics.
<!-- END:implementation-notes -->
