Deferred Copilot finding (PR #255 cycle 8, `retrieval_eval.rs:344`; single reviewer, P2, observability-metric class). The cycle-7 qualifier-aware denominator in `count_call_sites` keys distinct call sites on `(caller, callee, raw_qualifier, qualifier_kind)`. When two DIFFERENT spellings that resolve to the SAME target appear in one caller — e.g. `helper()` and `crate::thing::helper()` — the numerator counts 1 resolved edge (edges are keyed `(from, to)`) but the denominator counts 2 tuples, so recall UNDER-reports (0.5) for a case that is genuinely fully resolved.

This is the inverse error of the cycle-7 C7-1 fix (which removed an OVER-report that could hide real misses). The two error directions are mutually exclusive with a purely syntactic per-file denominator: the numerator is post-resolution node identity, the denominator is pre-resolution syntax. Fail-closed observability mandates the SAFE (under-report) direction — a recall metric must never over-state coverage — so the cycle-7 change is correct to keep. Scope for a truer metric: (1) make the denominator resolution-aware by collapsing distinct spellings that resolve to the same `(caller, target-identity)` into one expected edge, (2) reconcile it against the same identity space the numerator uses, (3) add fixtures for the same-target multi-spelling case and the distinct-target case. Low priority: observability-only, single-reviewer, under-report is the fail-closed-safe direction.
