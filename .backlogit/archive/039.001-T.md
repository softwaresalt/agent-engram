## Description

Add `#[ignore]` annotations with structured root-cause documentation to the two
integration tests that fail because CozoDB 0.7.6 panics when opening SQLite in
a daemon subprocess context on Windows.

**Affected tests:**

- `smoke_full_tool_chain_over_ipc` in `tests/integration/smoke_test.rs`
- `daemon_rehydrates_graph_and_vector_state_after_db_directory_is_deleted` in
  `tests/integration/graph_vector_rehydration_test.rs`

**Root cause:** CozoDB 0.7.6 `storage/sqlite.rs:49` calls `unwrap()` on
`conn.prepare()` during database open. In subprocess contexts on Windows, this
panics before the daemon can bind IPC.

## Acceptance Criteria

- Both tests carry `#[cfg_attr(target_os = "windows", ignore)]` with explanatory
  doc comment referencing root cause and tracking stash `100EACD8`
- `cargo test` runs both tests on Linux/macOS; skips on Windows
- `cargo clippy -- -D warnings -D clippy::pedantic` passes
