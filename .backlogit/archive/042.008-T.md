## Scope

Modify `src/bin/engram.rs`:
- Add new Command variants using `#[command(name = "...")]` for hyphenated names
- Add `GlobalFlags` as `#[command(flatten)]` on top-level `Cli` struct
- Wire each new variant to `cli::run()` dispatcher

Write parser regression tests (`tests/unit/cli_parser_test.rs`):
- default (no subcommand) → Shim
- `engram shim` → Shim
- `engram daemon --workspace /tmp/ws` → Daemon (existing internal command)
- `engram install`, `engram update`, `engram reinstall`, `engram uninstall`
- New subcommands parse with correct argument extraction
- Bad args produce appropriate parse errors

## Acceptance Criteria

- All existing commands continue to parse correctly (no regressions)
- `engram daemon --workspace <path>` still spawns the daemon (not confused with daemon-status)
- All 18 new CLI subcommands parse and route to cli::run()
- GlobalFlags are accessible from all handlers
- Parser regression tests pass for both old and new commands

## Execution Posture

Test-first: write parser tests, then wire integration.
