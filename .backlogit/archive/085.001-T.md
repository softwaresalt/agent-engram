<!-- BEGIN:acceptance-criteria -->
- `extract_dax_references` returns correct columns/bracket_refs/functions for qualified refs ('Table Name'[Col], Table[Col]), bare bracket refs [Name], and function calls.
- Brackets/quotes inside string literals ("...", "" escapes) and comments (// ..., /* ... */) are ignored.
- VAR/RETURN local identifiers (bare, not table-qualified, not followed by a `[` bracket or a `(` function-call delimiter) are ignored.
- Nested whitespace inside `[ ]` and `' '` preserved verbatim; `''` escaped quotes inside a quoted table token AND `]]` escaped closing brackets inside a bracketed name (per R2) handled, so a valid name containing `]` is neither truncated nor misattributed.
- `extract_dax_references` surfaces lexer `diagnostics` for unterminated constructs — unterminated string (`"..."`), quoted table identifier (`'...`), block comment (`/* ...`), or `[ ]` bracket — so a truncated ref like `'Sales[Amount]` is flagged, not silently dropped; well-formed input yields an empty `diagnostics`. This is the syntax-validation seam P5's `dax.malformed_ref` rule consumes.
- `cargo test -p powerbi-tmdl-parser` passes; module is safe (no unsafe), dependency-free.
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Create new module `crates/powerbi-tmdl-parser/src/dax.rs` exposing `pub fn extract_dax_references(expr: &str) -> DaxReferences` with `DaxReferences { columns: Vec<DaxColumnRef>, bracket_refs: Vec<String>, functions: Vec<String>, diagnostics: Vec<DaxDiagnostic> }`, `DaxColumnRef { table: Option<String>, column: String }`, and `DaxDiagnostic` (unterminated string / quoted table identifier / block comment / `[ ]` bracket) as the stable syntax-validation seam P5 consumes. Implement a single left-to-right, string/comment-aware state machine (Normal | InString | InLineComment | InBlockComment). Only in Normal state recognize: table tokens ('Quoted Name' or bare Ident), bracket tokens [ ... ], qualified column refs (table token immediately followed by bracket), unqualified bracket refs (pushed to both provisional columns table=None AND bracket_refs), and function calls (identifier immediately followed by '('). This is the STABLE SEAM: a future tree-sitter DAX grammar swaps in behind this signature without touching downstream. No downstream wiring in this task. Width: parser crate only.
