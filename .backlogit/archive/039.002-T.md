## Description

The `run_script_busy_retry_mutable` helper in `src/db/cozo_queries.rs`
retries SQLITE_BUSY errors silently. Added `tracing::warn!` logging to
each retry attempt for production observability.

Also fixed pre-existing unmasked bugs:
- `record_query_metrics` now emits `tracing::warn!` for slow queries (>100ms)
- `find_symbols_by_name` now records `symbol_lookup` timing via `record_timing`
- `connect_db` fd-lock timeout widened 5s → 30s to prevent CI flakiness

## Acceptance Criteria

- Each retry attempt emits `tracing::warn` with attempt count, max attempts,
  delay in ms, and error message
- `cargo clippy -- -D warnings -D clippy::pedantic` passes
- `cargo test` passes (retry behavior unchanged)
