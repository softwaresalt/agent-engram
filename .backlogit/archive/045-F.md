title: CLI-Direct (Daemonless) Mode for Indexing Operations
updated_at: 2026-05-08T22:50:19Z
---

Add a `--direct` flag to `engram sync` and `engram index` that bypasses the daemon and operates directly on the CozoDB database. Enables one-shot CLI usage and `start.ps1` preloading without spawning a persistent daemon process.

Uses `DaemonLock` for mutual exclusion — CLI-direct and daemon cannot run in parallel on the same workspace.
