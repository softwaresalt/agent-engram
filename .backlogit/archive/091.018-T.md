Deferred adversarial finding (gpt-5.6-sol, PR #255 cycle 5 panel; single reviewer, P2, rare). `extract_use_graph` records `use` bindings and local roots but NOT `extern crate ext as demo;` alias declarations. The resolver's workspace-crate fast path therefore cannot see that `demo` has been rebound to an external crate, so `demo::build()` — where a workspace crate is also literally named `demo` — can forge a false canonical edge to the workspace crate. This is the same shadowing class the cycle-5 F1 fix closed for `use ... as` renames and local `mod`/type roots, but via the (largely obsolete, Rust-2015-era) `extern crate ... as` form.

Blast radius is bounded by the fail-closed invariant (resolution may only DROP edges, and the collision requires BOTH a workspace crate named `demo` AND an `extern crate ... as demo` in the same file). Scope for a fix: (1) record extern-crate rename aliases in `UseGraph` (parse `extern_crate_declaration` nodes with an `alias`), (2) treat a re-pointed extern-crate alias as a shadow in `resolve_core` (fall through / fail closed exactly like a `use ... as` rename), (3) add a regression fixture asserting no stray edge for `extern crate ext as demo; demo::build();`. Low priority: rare, adversarial-only, single-reviewer, and deliberately out of scope for the 088-S cycle-5 fix set to avoid a broader use-graph change mid-review.
