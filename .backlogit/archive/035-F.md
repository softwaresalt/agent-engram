## SQL Reference Resolution Hardening

## Description

Harden the SQL reference-resolution subsystem with performance optimizations,
schema tuning, code deduplication, and improved resolution heuristics. Addresses
four follow-up items from 013-S (SQL Parser Enhancements) closure.

Scope: `src/db/queries.rs`, `src/db/schema.rs`, `src/services/code_graph.rs`

## Acceptance Criteria

- `references` table has a `target` index for query performance
- `reresolve_references_edges` uses batch class lookup (not N+1)
- Reference-resolution logic exists in one place (DRY)
- Case-insensitive and quoted-identifier resolution works for Class nodes
- All existing tests pass; new contract tests verify each improvement
