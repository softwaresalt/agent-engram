REHYDRATE PROVENANCE (added per Copilot #240 cycle-3 finding 1 — the export half is 082.011-T; this task is the JSONL read-back / rehydrate half so `resolution` survives a daemon restart/rehydrate rather than being silently reset to `direct`).

Files (<=3: 1 src + 1 test): src/services/hydration.rs (two edits in this one file: (a) add `resolution: Option<String>` to the `ParsedEdge` deserialize struct at :296 with `#[serde(default)]`, matching the existing import_path/linked_by pattern; (b) in `upsert_edge` at :459, change the `"calls"` arm (:460-463) to persist provenance via the `create_calls_edge_with_resolution(from, to, resolution)` writer added by 082.003-T, passing `edge.resolution.as_deref().unwrap_or("direct")`). Test: tests/integration/calls_resolution_rehydrate_test.rs.

Contract: today a rehydrated calls edge loses provenance — `ParsedEdge` (hydration.rs:296) has no `resolution` field and the calls upsert calls the 2-arg `create_calls_edge(from, to)` (:462) which hardcodes `resolution="direct"`. So after `serialize_edges_jsonl` writes a `calls_resolved_singleton` edge (082.011-T) and the daemon restarts, rehydrate would silently downgrade it to `direct`, corrupting eval/consumer weighting. This task deserializes `resolution` from the JSONL line and writes it back through `create_calls_edge_with_resolution`, so the full round-trip DB → export (082.011-T) → JSONL → rehydrate → DB preserves the exact provenance string. Backward-compatible: pre-field JSONL (no `resolution` key) deserializes to `None` and defaults to `direct`.

Width: hydration. Scenarios (3): a JSONL calls edge with `resolution:"calls_resolved_singleton"` rehydrates into the DB with that exact provenance (NOT downgraded to `direct`); a JSONL calls edge with no `resolution` key rehydrates as `direct` (backward compat); full round-trip — build edges, `serialize_edges_jsonl`, re-parse + `upsert_edge`, then `count_calls_edges_by_resolution` matches the pre-export provenance split.

Depends on 082.003-T (DB column + `create_calls_edge_with_resolution` writer) and 082.011-T (CodeEdge model + export path producing provenance-tagged JSONL).
