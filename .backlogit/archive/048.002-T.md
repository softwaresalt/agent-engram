Implement `neighborhood` and `transitive_closure` operations. `neighborhood` delegates to existing `bfs_impl` with edge-type filter, adding backlog edge tables (`backlog_edge` with from_id/to_id columns). `transitive_closure` implements directed BFS collecting all reachable nodes via specified edge types in specified direction, capped at `max_nodes` (default 100). All operations return `GraphQueryResult { nodes, edges, truncated, operation }`. Hard cap of 500 result nodes. Test-first: 2 contract tests (neighborhood returns correct BFS shape, transitive_closure collects reachable nodes).
