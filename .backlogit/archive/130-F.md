title: Tolerate Copilot pre-initialize server/discover probe in the Engram MCP shim
updated_at: 2026-08-24T04:28:33.6816953Z

Add a narrow pre-initialize compatibility layer so the shim answers JSON-RPC -32601 (Method not found) to Copilot's server/discover probe and continues waiting for a standards-compliant initialize, instead of exiting with TransportFailure (exit 13). Interception allowlist is exactly server/discover; every other frame forwards to rmcp unchanged. Gated by ENGRAM_MCP_PREINIT_COMPAT (default on). Preserves normal MCP clients, stdout JSON-RPC purity, serve-first/degraded-session behavior, exit-code taxonomy, and rmcp tool behavior. No new dependency. Explicitly does NOT increase the daemon readiness timeout, and excludes the independent Cozo cold-start defect.
