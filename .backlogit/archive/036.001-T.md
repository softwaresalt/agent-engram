cozo-0.7.6 SQLite unwrap() panic in open_sqlite_db() fires when multiple daemon processes open the same SQLite file concurrently. Affects all integration tests spawning CozoDB daemons. CI workaround: continue-on-error on cozo-backend test step.

Fix options: upgrade cozo to a version with WAL mode or proper error handling, or add process-level locking around DB open in the daemon.
