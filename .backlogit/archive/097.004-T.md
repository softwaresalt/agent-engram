W1 — any DataFrame reassignment, INCLUDING a second read into the same binding, must invalidate the dataflow chain per U2b / 095.004-T. Domain: python-parser / dataflow (single file). Plan Unit W1.

PROBLEM. The U2b single-cell resolver `resolve_cell_candidates` (src/services/parsing/python.rs; the resolved-`ReadBind` arm ~L1296-1315) unconditionally `binding.insert(variable, endpoint)`. When a variable is ALREADY tracked, a second top-level Spark read into it silently REBINDS to the new source instead of invalidating. Example — `df = spark.read.parquet("a")` then `df = spark.read.parquet("b")` then `df.write.saveAsTable("t")` — currently emits an edge `t <- b`. Per the U2c/U2b fail-closed doctrine (F2 / AR-02 / AR-29), a reassignment of a tracked binding — even a second read — is ambiguous for the single-binding resolver and must break the chain (emit NO edge), not pick the later read.

CHANGE. In `resolve_cell_candidates`, in the resolved-top-level-`ReadBind` arm, before inserting: if `variable` is ALREADY present in `binding` (or already in `invalidated_sessions`), treat the re-read as a rebind of a tracked binding and INVALIDATE — `binding.remove(variable)` and `invalidated_sessions.insert(variable.clone())` — rather than rebinding. The FIRST read of a fresh variable still binds normally (AR-02: the assignment IS the read, no self-invalidation). Confine the change to the resolver; `handle_assignment`/`push_invalidate` event emission is unchanged (U2c remains the single event source of truth).

FILE TARGETS. src/services/parsing/python.rs only (`resolve_cell_candidates` + tests in the existing `tests` module).

ACCEPTANCE CRITERIA (test-first):
- AC1 (second-read invalidates): `df=spark.read(a); df=spark.read(b); df.write(t)` in one cell emits NO edge.
- AC2 (single-read happy path preserved): `df=spark.read(a); df.write(t)` still emits `t <- a` (no recall regression).
- AC3 (no regression): existing `u2b_*` tests — atomic bind→write with no self-invalidation, per-form rebind invalidation, nested-destructuring rebind, cross-cell rejection — all still pass.

FAIL-CLOSED INVARIANT. Only DROPS edges from ambiguous multi-read bindings (013-D precision floor: 0 false edges). Learning applied: docs/compound/best-practices/python-bare-call-edge-extraction-body-scoped-2026-07-20.md (body-scoped fail-closed Python extraction). ARCHITECTURE NOTE (P2 review): single caller (per-cell notebook router); confirm no other caller relies on last-write-wins rebind.

Harness-ready: RED (AC1) then GREEN via the invalidate-on-retracked-binding guard. No schema/API change. Parallel with V2/V5/W2/V4; feeds X1 version bump.
