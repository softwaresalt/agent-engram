Reopen the tree-sitter TMDL grammar track after the 2026-07-04 safe-consumption
correction dispelled the `#![forbid(unsafe_code)]` blocker (Engram already
consumes ten C-based tree-sitter grammars — eleven languages — through the safe
`Parser::set_language(&tree_sitter_x::LANGUAGE.into())` API with zero `unsafe`).
This umbrella hosts the corrected evaluation gate (066.008-T, unblocked) and any
ROI-justified first-slice work: a vendored/generated TMDL grammar with an
external indentation scanner, a fixture-derived corpus, pinned grammar ABI, and
DAX/M captured as opaque blocks — integrated inside the Power BI ingestion
boundary (`crates/powerbi-tmdl-parser` → `src/services/powerbi_tmdl.rs`), never
as a generic code-graph `Language`. Predecessor safe-parser depth work landed in
068-F/068-S. Spike: docs/decisions/2026-07-04-tmdl-tree-sitter-safe-consumption-correction-spike.md.

## Resolution (2026-07-04) — DECLINE, feature retired

The 069-F evaluation gate (066.008-T differential-evaluation harness, shipped in
069-S / PR #196) concluded **DECLINE** with high confidence. The differential
harness (`tests/unit/tmdl_differential_eval_test.rs`, 11 tests) measured the safe
`parse_tmdl_document` at **3 PASS / 6 MISS**, but no miss is a material,
hard-to-fix-incrementally mis-parse that a tree-sitter grammar would resolve:
4 misses are model-richness gaps (relationship qualifiers, `hierarchy`/`level`,
`calculationGroup`, RLS `role`) that need `TmdlModel`/adapter extensions
independent of parse technology; 2 are incrementally-fixable safe-parser
heuristic bugs (calculated-column `column X = <DAX>` mis-scoping; measure DAX
containing `:` truncated by the `contains ':'` property shortcut at `lib.rs:1128`).

**Outcome:** a tree-sitter TMDL grammar is not ROI-positive; the safe parser is
sufficient. No grammar follow-on tasks promoted. Feature retired as `done`.
Finding: `docs/decisions/2026-07-04-tmdl-eval-gate-finding.md`. The two safe-parser
bugs are recorded (pinned by harness assertions) as candidate small follow-ups,
not part of this feature.
