# Immutable compatibility fork for SQL CREATE PROCEDURE

## Problem Frame

<!-- BEGIN:problem-frame -->
tree-sitter-sequel 0.3.11 cannot parse CREATE PROCEDURE, while upstream PR #355 merged at f5480941b00ce267f6fe0fb03a066809ade0bc16 and emits create_procedure, which agent-engram already matches. No qualifying crates.io release exists. A raw upstream Git pin fails because generated src/parser.c and src/*.json are ignored although Rust build.rs compiles parser.c. The decision must enable repository-owned adoption without treating external fork creation or publication as agent-engram executable scope.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
Selected: operator-controlled immutable compatibility fork containing reviewed generated artifacts and pinned by full SHA. Rejected absent new evidence: indefinite crates.io release wait; direct upstream Git pin lacking generated files; vendoring unreviewed generated C into agent-engram; cross-repository fork creation as an agent-engram task; floating branch or tag pins.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Use a fail-closed external/manual prerequisite for an operator-approved compatibility fork. The evidence packet must name the fork URL and exact 40-character commit; show minimal source delta from upstream PR #355; inventory and SHA-256 hashes for generated parser artifacts; record tree-sitter-cli@v0.26.3 identity and reproducible generation procedure; preserve MIT licensing/notices; prove supported Linux, Windows, and macOS Rust builds/tests in fork CI; and define maintainer, compromise response, staleness review, and retirement to a qualifying upstream release. Harvest only agent-engram tests, immutable Cargo pin/lock/provenance, existing parser/doc activation, verification, and operational closure. Do not assemble a claimable shipment until the packet is approved.
<!-- END:chosen-direction -->

## Open Questions

<!-- BEGIN:open-questions -->
External prerequisite unresolved: approved fork repository, full immutable SHA, generated-artifact inventory/hashes, source-delta review, license review, generator attestation, and cross-platform CI URLs do not yet exist in this session. Operator must also name the approver and fork lifecycle owner. A future qualifying upstream release triggers retirement review, not automatic repinning.
<!-- END:open-questions -->

## Notes

<!-- BEGIN:notes -->
Focused feasibility/trust-boundary spike result: feasible only through reviewed generated C artifacts because build.rs unconditionally compiles parser.c. ABI gate must prove generated language ABI is accepted by agent-engram tree-sitter 0.25 on every supported platform before dependency adoption. RED-first contract should assert the grammar produces a named create_procedure node and extraction returns exactly one Function named archive_old_orders while CREATE FUNCTION and unsupported/error graceful-degradation behavior remain green. Compromise trigger: hash/signature/repository-control anomaly, unexplained source delta, CI provenance loss, or security advisory; response is stop release, revert Cargo.toml/Cargo.lock to crates.io 0.3.11, restore zero-symbol procedure expectation/docs, and rebuild from trusted lock. Staleness: review fork and upstream release state at each dependency update and at least every 90 days. Observability: CI artifact/provenance checks plus 72-hour post-release smoke across supported platforms, tracking parse errors/panics and missing or duplicate procedure symbols.
<!-- END:notes -->
