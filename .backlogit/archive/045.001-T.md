Create `src/cli/direct.rs` — a lightweight runner for CLI-direct (daemonless) indexing operations.

## Implementation

1. Add a new module `src/cli/direct.rs` with a `run_direct()` function
2. `run_direct()` accepts `(method, ws_path, formatter)` and:
   - Resolves workspace root via `canonicalize_workspace()`
   - Acquires `DaemonLock::acquire(workspace)` — exit with code 2 and clear error if `AlreadyHeld`
   - Calls `resolve_data_dir()`, `resolve_git_branch()`, `parse_config()`
   - Dispatches to `index_workspace()` or `sync_workspace()` from the services layer
   - Formats the result via `OutputFormatter` (JSON or text)
   - Drops `DaemonLock` on exit (automatic via RAII)
3. Register `mod direct;` in `src/cli/mod.rs`

## Acceptance Criteria

- `run_direct()` compiles and can be called from the CLI subcommand handlers
- `DaemonLock` prevents concurrent operation with daemon
- Config is loaded via `parse_config()` (not from `AppState`)
- `cargo test` passes
- `cargo clippy -- -D warnings -D clippy::pedantic` clean

## Scope

- `src/cli/direct.rs` (new file)
- `src/cli/mod.rs` (add `pub mod direct;`)
