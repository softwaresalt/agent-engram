Create two install scripts that download the latest engram release binary from GitHub Releases and place it on PATH.\n\n**scripts/install.ps1** (PowerShell, IRM-compatible):\n- Invoked via: `irm https://raw.githubusercontent.com/softwaresalt/agent-engram/main/scripts/install.ps1 | iex`\n- Query GitHub Releases API for latest release tag\n- Download the Windows x86_64 zip archive (engram-{tag}-x86_64-pc-windows-msvc.zip)\n- Extract engram.exe to a user-local directory (e.g. $HOME/.engram/bin)\n- Add to PATH if not already present (user-scope PATH modification)\n- Print success message with next-steps hint\n\n**scripts/install.sh** (bash, curl|sh-compatible):\n- Invoked via: `curl -fsSL https://raw.githubusercontent.com/softwaresalt/agent-engram/main/scripts/install.sh | sh`\n- Query GitHub Releases API for latest release tag\n- Detect platform: Linux x86_64 → x86_64-unknown-linux-gnu, macOS ARM → aarch64-apple-darwin\n- Download the appropriate tar.gz archive (engram-{tag}-{target}.tar.gz)\n- Extract engram binary to ~/.engram/bin\n- Add to PATH via shell profile (~/.bashrc, ~/.zshrc) if not already present\n- Print success message with next-steps hint\n\n**Both scripts must:**\n- Handle errors gracefully (network failures, unsupported platforms)\n- Be idempotent (safe to re-run for upgrades)\n- Use HTTPS for all downloads\n- Not require elevated/root privileges\n- Work with the current archive naming convention from release.yml

<!-- BEGIN:acceptance-criteria -->
- scripts/install.ps1 exists and is IRM-compatible
- scripts/install.sh exists and is curl|sh-compatible
- Both detect platform and download correct archive
- Both extract binary to ~/.engram/bin and update PATH
- Both handle errors (unsupported platform, network failure)
- Both are idempotent for re-runs/upgrades
- No elevated privileges required
<!-- END:acceptance-criteria -->

<!-- BEGIN:implementation-notes -->
Archive naming from release.yml: engram-{tag}-{target}.{ext}
Targets: x86_64-unknown-linux-gnu (.tar.gz), x86_64-pc-windows-msvc (.zip), aarch64-apple-darwin (.tar.gz)
GitHub API: https://api.github.com/repos/softwaresalt/agent-engram/releases/latest
Install dir: ~/.engram/bin (cross-platform convention)
Repo: softwaresalt/agent-engram
