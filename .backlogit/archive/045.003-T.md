Write integration tests that verify CLI-direct mode behavior.

## Test Cases

1. **Direct sync on clean workspace**: `engram sync --direct --json` on a workspace with Rust files produces a valid `SyncResult` JSON and exits 0
2. **Direct index on clean workspace**: `engram index --direct --json` produces a valid `IndexResult` JSON and exits 0
3. **Mutual exclusion**: Start a daemon, then run `engram sync --direct` — verify it exits with code 2 and a clear error message about the daemon holding the lock
4. **Env var**: Set `ENGRAM_DIRECT=1`, run `engram sync --json` — verify it uses direct mode (exits 0 without a daemon running)
5. **No orphaned processes**: After `engram sync --direct` exits, verify no `engram` daemon process is running

## Acceptance Criteria

- All 5 test cases pass
- Tests use `DaemonHarness` pattern from `tests/helpers/mod.rs` where needed
- Tests are in `tests/integration/cli_direct_test.rs`
- `cargo test` passes
