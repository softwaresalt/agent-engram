# Restore hidden engram doctor --smoke CLI readiness workflow to unblock 177-S (142.058-T F54d)

## Problem Frame

<!-- BEGIN:problem-frame -->
During `177-S` (`142.058-T`, F54d), the descriptor-generated cross-surface parity matrix in `tests/contract/read_server_cli_mcp_parity_test.rs` invokes `engram --workspace <W> --json doctor --smoke` because `src/tools/capabilities.rs:527-535` declares `DOCTOR_SMOKE` (`"doctor --smoke"`) on `CLI_ONLY` (`CapabilityClass::Read`, `read_server_available: true`, `generation_backed: false`, `input_ownership: InputOwnership::CliFrontend`) and `src/tools/doctor.rs:288` implements mode-aware `run_smoke_test(workspace)`. However, `src/bin/engram.rs` has no `Doctor` subcommand variant, causing the shipped binary to exit `2` with `error: unrecognized subcommand 'doctor'`. Under P-021 C1, `142.058-T` owns only `tests/contract/read_server_cli_mcp_parity_test.rs` and cannot add production CLI code or weaken the matrix.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
Option 1 (Chosen): Restore the declared `doctor --smoke` CLI readiness workflow as a hidden subcommand (`#[command(hide = true)] Doctor { #[arg(long, required = true)] smoke: bool }`) co-located with `run_health` in `src/cli/commands/report.rs`, calling `crate::tools::doctor::run_smoke_test(&workspace)` directly and emitting standard `OutputFormatter` JSON-RPC 2.0 envelopes (`0` on `passed: true`, `1` on `!passed` or `EngramError`, `2` on Clap/workspace-resolution error), delivered in prerequisite one-task shipment `Slot-20c.1` before `177-S`.
Option 2 (Rejected): Remove `DOCTOR_SMOKE` (`"doctor --smoke"`) from `src/tools/capabilities.rs` and delete its CLI mapping in `tests/contract/read_server_cli_mcp_parity_test.rs`. Rejected because `142.005-T` (F19), `142.039-T` (F30), `contract_tool_descriptor_registry`, and `integration_doctor_read_pin` explicitly pin `doctor --smoke` as an authoritative ReadServer readiness workflow.
Option 3 (Deferred as future tech-debt evaluation): Immediately fold `doctor --smoke` into `engram health` (e.g., `engram health --smoke`) and rewrite `DOCTOR_SMOKE` across `capabilities.rs`, `tool_descriptor_registry_test.rs`, and `142.058-T`. Deferred because changing descriptor names and `142.058-T`'s frozen `6d216d19` parity matrix mid-`142-F` expands blast radius across multiple completed `142-F` units; captured as a post-`142-F` consolidation task per operator direction.
<!-- END:options -->
