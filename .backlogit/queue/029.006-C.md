# WS-6 Background offline-change scan

Refactor `set_workspace` to return immediately after binding with `pending_scan: true`. Move offline-change detection to a background `tokio::spawn` task using `Arc<AppState>`. Progress visible via `get_workspace_status` (`scan_status: Option<ScanProgress>`). Scan completion triggers re-index. Generation counter handles concurrent scan/sync requests.

<!-- BEGIN:AcceptanceCriteria -->
- [ ] `set_workspace` bind response returns within 500ms even on large workspaces
- [ ] Response includes `pending_scan: true` when scan is in progress
- [ ] `get_workspace_status` reports scan progress and completion
- [ ] Scan completion triggers re-indexing when offline changes detected
- [ ] Concurrent set_workspace/sync_workspace cancels stale scan via generation counter
