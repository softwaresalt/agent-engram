## Scope

Write integration tests (`tests/integration/cli_e2e_test.rs`) that spawn the binary:

- `engram manifest --json` → valid JSON-RPC 2.0 with tools array (TOOL_COUNT entries)
- `engram daemon-status --json` → JSON-RPC response (success or error depending on daemon state)
- `engram sync --json --workspace <test_ws>` → indexing response (with test workspace)
- Exit code 0 on success, exit code 1 on tool error, exit code 2 on bad args
- `--id 42` → response contains `"id":42`
- `--format=text` → non-JSON human-readable output

## Acceptance Criteria

- At least 6 e2e tests covering: manifest, lifecycle, indexing, exit codes, --id, text mode
- Tests use `std::process::Command` to spawn the binary
- Tests parse stdout as JSON and validate schema
- Tests verify exit codes match expected values
- All tests pass in CI (no daemon dependency for manifest test)

## Execution Posture

Test-first: write test harnesses first (expect failures), then ensure binary satisfies them.
