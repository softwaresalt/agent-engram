Plan unit F24 - read-input ownership inventory. Exhaustively classify every input reachable from every Read descriptor into exactly one of three classes: generation-owned, pinned operational, or disallowed in ReadServer mode. Write the inventory as an executable contract in `tests/contract/read_input_ownership_inventory_test.rs` that FAILS when a new unclassified input appears.

This inventory is the specification the F37 static pinning guard enforces and the reason the handler migrations (F25-F36) can be verified rather than assumed.

Execution posture: test-first exhaustive classification.

<!-- BEGIN:acceptance-criteria -->
- Every input reachable from every Read descriptor is enumerated.
- Each input is classified as exactly one of: generation-owned, pinned operational, disallowed in ReadServer mode.
- Each non-database input is classified explicitly, not by omission.
- `get_retrieval_eval_report` stays MCP-only; no CLI surface is implied by the inventory.
- `_health` stays direct-IPC-only.
- The contract test FAILS when a new input appears without a classification.
- The inventory is the single source F37 enforces against.
