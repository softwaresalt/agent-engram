Add the single-cell DataFrame dataflow resolver (Fork E Option b) that links read events to write events WITHIN ONE notebook cell and emits LineageEdgeCandidates. CONSUMES U2's Vec<SparkLineageEvent> event stream — READ BIND events, WRITE CALL events, AND NON-SPARK REBIND/INVALIDATION events (cycle-5 F2 / AR-02) — using each event's receiver variable + source order + enclosing scope; performs NO second AST walk (U2 is the single extraction source of truth). Track df_var -> dataset bindings from atomic READ BIND events (df = spark.read...(literal) / spark.table(literal)) — a read Bind does NOT self-invalidate (AR-02) — then when a WRITE CALL event on the SAME variable (df.write.saveAsTable/save(literal), receiver = the chain-root simple-name) appears LATER in source order within the SAME top-level cell scope, emit a LineageEdgeCandidate { target: write_dataset, sources: [read_dataset] } (the shared directional carrier U4 flattens to lineage_derives_from edges). RETURN TYPE: Vec<LineageEdgeCandidate> (cycle-5 F3 — a directional target<->sources carrier, not a flat endpoint list). FAIL CLOSED — drop (no edge) on: df REASSIGNMENT — ANY rebind event for the tracked variable before the write, whether to another Spark read, a NON-SPARK expression (df = other, incl. spark = other — AR-29), or an unresolvable RHS, invalidates the binding (cycle-5 F2 — now observable because U2 emits rebind events from its full AST walk, not only whitelisted Spark calls); NON-TOP-LEVEL scope (a binding or write whose event scope is not a DIRECT CHILD of the cell/module body — branch, loop, nested, comprehension, with/except target, del/augmented/walrus/import, def/class; AR-07); UNRESOLVED RECEIVER (receiver = None); a read event whose endpoint U2 left unresolved; or any non-literal in the chain. Cross-cell df propagation is OUT of v1. Pure — no persistence here. Tests: read->df->write in one cell -> a LineageEdgeCandidate U4 persists as derives edge (the read Bind does NOT self-invalidate — AR-02); df reassignment (df = other; df.write...) -> no edge (the non-Spark rebind event invalidates the binding — now achievable, cycle-5 F2); a rebind in EACH non-top-level form — branch, loop, comprehension, with/except, def/class — invalidates -> no edge (AR-07); unresolved receiver (write on a df never bound to a resolved read, or a non-simple-name receiver) -> no edge; read in cell A + write in cell B -> no cross-cell edge; a U2<->U2b CONTRACT TEST asserts U2 emits ALL THREE event kinds — atomic read Bind (receiver + source-order + scope), write call (chain-root receiver), AND the non-Spark rebind/invalidation event — that U2b consumes (findings E2 + cycle-5 F2 / AR-02).
