# 030-F Tier-2 code graph completion: verification, Markdown, SQL, deferred Kotlin

<!-- SECTION:DESCRIPTION:BEGIN -->
## Description

Complete the Tier-2 code graph language expansion begun in 027-F (shipped via 005-S). Three remaining gaps:

1. **End-to-end IPC verification** for swift/c/cpp grammars that landed in 005-S — confirm symbols persist to SurrealDB after a file-watcher event triggers indexing through the daemon, not just unit-tested in isolation.
2. **C++ inline member function extraction** — 005-S deferred traversal of `function_definition` nodes inside `class_specifier`. Required for accurate C++ symbol coverage.
3. **Markdown parser** — heading, code-block, link-reference extraction for .md/.mdx; unblocks docs/research indexing.
4. **SQL dialects spike** — evaluate tree-sitter-sql grammar crates and dialect coverage (T-SQL, PL/SQL, PostgreSQL, MySQL, SQLite) before committing to grammar wire-up. Outcome drives subsequent grammar tasks.
5. **Kotlin activation watch** — blocked on tree-sitter-kotlin publishing a 0.25-compatible release; tracked as a watch-and-bump backlog item, excluded from Shipment 003-S manifest.

All grammar crates must stay on the workspace ABI rule: tree-sitter runtime 0.25.x with grammar pins (most at 0.23.x for ABI 14, tree-sitter-swift pinned to =0.7.1 for ABI 15) per Cargo.toml convention.
