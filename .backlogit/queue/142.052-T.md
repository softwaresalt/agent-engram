Plan unit F44 - read-server lifecycle policy. Implement `src/daemon/lifecycle_policy.rs` against the F04a seam so a read-server daemon performs NO hydration, NO source scan, NO watcher registration, NO implicit sync, and NO shutdown graph flush.

This is the unit that actually delivers the reliability goal: the read server's startup and shutdown cost becomes independent of workspace size and watcher activity.

Execution posture: test-first.

<!-- BEGIN:acceptance-criteria -->
- ReadServer mode performs no hydration at startup.
- ReadServer mode performs no offline source scan.
- ReadServer mode registers no workspace watcher.
- ReadServer mode never triggers an implicit sync.
- ReadServer mode performs no graph flush at shutdown.
- Managed-mode lifecycle behavior is entirely unchanged.
- `tests/integration/read_server_lifecycle_test.rs` asserts the absence of each activity, not merely that startup is fast.
