Fail-closed guard against any rebind shadowing an imported name -- whether a MODULE RECEIVER (import bar; bar = factory(); bar.parse()) OR a BARE CALLEE (from bar import parse; parse = factory(); parse() -- Q1). Static binding-only resolution would still bind to bar.parse -> a false edge (013-D violation). The bare-callee vector was left open by cycle-1 (guard covered only module receivers). R3: the shadow guard lives ENTIRELY in T5c and WRAPS T5b's guard-agnostic resolution (T5b does NOT call the guard); the dependency is one-directional T5c->T5b, keeping both independently completable and the DAG acyclic. In the T5b Python branch of canonical_target_for_staged_call, AFTER T5b computes a candidate canonical target, T5c fails closed when the resolved name is re-bound by a LATER binding -- one that occurs AFTER the effective import binding in binding order (ORDER-AWARE, Y2) -- in the APPLICABLE scope (caller function AND module level), consuming the T2b (096.009-T) scope model. Applies to BOTH: qualifier_kind=="module" (the receiver name) AND qualifier_kind=="python_bare" (the bare callee name, when T5b resolved it via a FromImportSymbol binding or in-module def -- Q1). M1/X4: the rebind scan covers the FULL target set: plain assignment, augmented assignment (+=), for targets, with ... as, except ... as, walrus (:=), function parameters, def/class definitions, del statements, match/case capture patterns, and module-level rebinding. Y2 (order-aware): each of these invalidates the import binding ONLY when it occurs AFTER the import; a def/class/del/match-capture or any rebind BEFORE the import does NOT invalidate it (the import is then the last binding and T5b's resolution stands -- e.g. `def parse(); from bar import parse; parse()` -> bar.parse). A LATER rebind still drops the edge (e.g. `import bar; class bar: ...; bar.parse()` -> NO edge, X4). Effective binding order is module source order at module scope and, within a function, Python's function-local-for-whole-body rule (T2b, Y1). Reuse the already-loaded caller/module source (T5b/T2b context); cheap tree-sitter scan. No new DB call. TDD RED->GREEN. Domain: code.
