Plan unit F51 - PowerShell launcher wrapper. Rework `start.ps1` so Copilot is launched ONLY on F50 `Succeeded`, and so cleanup terminates exactly the launcher's own child process - never an unowned descendant or an unrelated daemon.

This replaces the existing 15-second fail-open wrapper that could release Copilot before indexing or functional readiness was established.

Execution posture: characterization-first supersession of 118-S Guardrail 4. RS4/RS5 - operator approval required before implementation.

<!-- BEGIN:acceptance-criteria -->
- Copilot launches only when the F50 preflight machine reports `Succeeded`.
- The previous 15-second fail-open release path is removed, not merely lengthened.
- On preflight failure the launcher reports the typed failing stage and does NOT launch Copilot.
- Cleanup terminates exactly the launcher's own child process, identified by ownership rather than by name or image.
- Unowned descendants and unrelated daemons are never terminated.
- Paths containing spaces are handled correctly.
- `tests/contract/start_launcher_test.rs` covers the success path and exact-child cleanup.
