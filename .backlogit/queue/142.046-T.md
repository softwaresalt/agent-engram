Plan unit F37 - read-path pinning enforcement. Add a static guard in `tests/contract/read_path_pinning_enforcement_test.rs` that FORBIDS, anywhere on the read path, a fresh `connect_db` call, a workspace snapshot read, a workspace-root read, or a `.engram` read - unless the F24 inventory explicitly classifies that input as pinned operational.

This is the unit that turns the F25-F36 migrations from "believed done" into "provably complete", and prevents regression as new read code is added.

Execution posture: test-first static enforcement.

<!-- BEGIN:acceptance-criteria -->
- The guard forbids fresh `connect_db` calls on the read path.
- The guard forbids post-entry workspace snapshot reads on the read path.
- The guard forbids workspace-root reads on the read path.
- The guard forbids `.engram` reads on the read path.
- Each exception is allowed ONLY when the F24 inventory classifies it as pinned operational.
- The guard fails when a new unclassified read-path input is introduced.
- The guard is GREEN only after all of F25-F36 have landed.
<!-- END:acceptance-criteria -->
