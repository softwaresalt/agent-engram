Stop wasting GitHub Actions minutes: skip the CI Rust build (~3-3.5min on ubuntu-latest) for PRs that touch only doc/backlog/non-code paths, while preserving full clippy+test coverage for any PR that touches code. Grounded by the required-check spike (docs/decisions/2026-07-04-ci-build-skip-required-check-spike.md): the build check is NOT a required status check on main (ruleset PR-Required id 12812291 enforces review + copilot-review only, no required_status_checks rule; PR #200 backlog-only ran a 3m14s build then merged with REVIEW_REQUIRED/--admin). Because no status check is required, a workflow-level paths-ignore on ci.yml (push + pull_request) for .backlogit, docs, markdown, and .autoharness paths is safe and sufficient — a single code file re-arms the whole workflow so code-PR coverage cannot be weakened. PR-title if conditional rejected (fragile/bypassable, no safer on required checks). release.yml (tag-triggered) out of scope. Plan: docs/exec-plans/2026-07-04-ci-build-skip-non-code-prs-plan.md.
