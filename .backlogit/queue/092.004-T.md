Deferred adversarial P2 (GPT-5.6 Sol @ xhigh) from 092.003-T. After 092.003-T migrated the four daemon background-sync closures in src/daemon/ipc_server.rs to the atomic AppState::snapshot_workspace_and_config() reader, the same non-atomic (workspace, config) paired-read race class still exists in the MCP tool handlers: src/tools/write.rs (index_workspace, sync_workspace) and src/tools/read.rs (map_code, impact_analysis) each read the active workspace and its config through two separate awaited reads, leaving the (workspace_i, config_j) tear window a concurrent set_workspace_and_config bind could open. Out of scope for 092.003-T, which was constrained to the daemon closures. Fix: migrate those handler sites to one atomic AppState::snapshot_workspace_and_config() snapshot per operation, preserving each site's existing skip/None-gating behavior; where a site currently substitutes WorkspaceConfig::default() on a missing config, prefer snapshot_dispatch_context (which already default-substitutes) rather than changing observable behavior. Add reader-side non-vacuous tests mirroring the daemon seam guard. Fail-closed / self-healing: the observable risk is a single tool invocation acting on a mismatched config during a concurrent bind, not data loss. Source: 092.003-T pre-Copilot adversarial review (P2-2).
