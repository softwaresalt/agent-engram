## Description

Add `backlog_node` and `backlog_edge` CozoDB relations to the schema, plus
CRUD query functions for batch insert, select, and delete operations.

## Scope

- `src/db/cozo_backend/schema.rs` (add CREATE_BACKLOG_NODE, CREATE_BACKLOG_EDGE)
- `src/db/cozo_queries.rs` (add upsert/select/delete functions)

## Implementation

- `backlog_node { id: String => title: String, kind: String, status: String, labels: String, file_path: String, content_hash: String, source_path: String, ingested_at: String }`
- `backlog_edge { from_id: String, to_id: String, edge_type: String => source_path: String }`
- `upsert_backlog_nodes(nodes: &[BacklogNode])` — batch `:put`
- `upsert_backlog_edges(edges: &[BacklogEdge])` — batch `:put`
- `delete_backlog_nodes_by_source(source_path: &str)` — remove all for source
- `select_backlog_nodes(source_path: Option<&str>)` — query nodes

## Tests

- `tests/contract/backlog_schema_test.rs` (4 scenarios):
  insert nodes, insert edges, query nodes back, delete by source_path

## Acceptance Criteria

- Schema bootstrap includes new relations (idempotent `:create`)
- Batch upsert handles 100+ nodes without error
- Delete by source_path removes all associated nodes and edges
- `cargo test` passes
