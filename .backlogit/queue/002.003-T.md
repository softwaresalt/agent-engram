## Description

Add `backlog_node`, `backlog_edge`, and `backlog_content_record` CozoDB relations to the
schema, plus CRUD query functions for batch insert, select, and delete operations.

## Scope

- `src/db/cozo_backend/schema.rs` (add CREATE_BACKLOG_NODE, CREATE_BACKLOG_EDGE, CREATE_BACKLOG_CONTENT_RECORD)
- `src/db/cozo_queries.rs` (add upsert/select/delete functions)

## Implementation

- `backlog_node { id: String => title: String, kind: String, status: String, labels: String, file_path: String, content_hash: String, source_path: String, ingested_at: String }`
- `backlog_edge { from_id: String, to_id: String, edge_type: String => source_path: String }`
- `backlog_content_record { file_path: String => content_type: String, content_hash: String, content: String, embedding: String, source_path: String, ingested_at: String }` — separate from generic `content_record` to avoid key collisions when backlog paths overlap `docs/` paths already indexed
- `upsert_backlog_nodes(nodes: &[BacklogNode])` — batch `:put`
- `upsert_backlog_edges(edges: &[BacklogEdge])` — batch `:put`
- `upsert_backlog_content_record(records: &[BacklogContentRecord])` — batch `:put`
- `delete_backlog_node_by_file_path(file_path: &str)` — per-file deletion (removes node + associated edges + content record for that file only)
- `delete_backlog_nodes_by_source(source_path: &str)` — source-wide removal (for registry source removal only)
- `select_backlog_nodes(source_path: Option<&str>)` — query nodes
- `select_backlog_content_records(source_path: Option<&str>)` — query content records

## Tests

- `tests/contract/backlog_schema_test.rs` (5 scenarios):
  insert nodes, insert edges, insert content records, query nodes back,
  per-file deletion removes node+edges+record without affecting other files

## Acceptance Criteria

- Schema bootstrap includes all three new relations (idempotent `:create`)
- Batch upsert handles 100+ nodes without error
- Per-file deletion removes only the target file's node, edges, and content record
- Source-wide deletion removes all items for a registry source (for source removal)
- `cargo test` passes
