<!-- BEGIN:description -->
Extend the T2 bindings into a scope-aware model (M1): a file-wide flat map leaks a function-local import into other callers and cannot represent module-level rebinding. The extractor-reachable CALLER is always a TOP-LEVEL function body (Anchor A), whose applicable scope chain is just {function-local -> module}. The model still REPRESENTS nested-function scopes, but only to ISOLATE them: a nested/closure function's local import must never leak UP into its enclosing top-level caller (F5). The resolver consults a reachable (top-level) caller's own function-local bindings, then module-level (a top-level function has no enclosing-function scope), honoring `global`. C12-4/T-d (Anchor C): a dynamic `global`/`nonlocal` WRITE that rebinds a name in another scope makes sibling callers run-order-dependent -> such a write INVALIDATES (fails closed) sibling callers of that name (the call inside the writing function itself ALSO fails closed -- it observes the dynamic-write result, not a statically provable function; resolving the RHS is a v1 non-goal; `from a import f; def mutate(): global f; from b import f; def caller(): f()` -> caller() fails closed). A function-local import must NEVER leak to a sibling; nested-function locals must not leak up to the enclosing top-level caller. A name whose applicable (function-local or module) scope holds a competing binding fails closed (reuses the M1 rule from T2). NON-GOAL (v1, Anchor A): resolving a nested/closure function AS A CALLER against an enclosing-function binding (and `nonlocal` chains) is out of scope -- the extractor stops at nested function_definition/lambda and never emits their calls; do NOT add nested extraction. Y1 (function-local import ordering): a function-local import binds its name for the WHOLE function body (Python UnboundLocalError semantics); track binding AND call positions so a call BEFORE a function-local import emits NO edge -- a POISON/TOMBSTONE that must NOT fall through to the module scope (F8) -- and only calls AFTER it resolve; uncertain control-flow ordering fails closed. TDD RED->GREEN. Domain: code.
