- Function-local `from x import f` is visible for a call AFTER it; but a call BEFORE the function-local import (`def g(): f(); from x import f`) gets NO binding/edge -- fail closed as a POISON/TOMBSTONE that does NOT fall through to a module-level `f` (Y1/F8: `f` is function-local for the whole body, UnboundLocalError at that call).
- M1: the SAME call site in a sibling function lacking the import gets NO binding (no leak).
- F5 closure chain: a nested function's bare call resolves against an ENCLOSING function's import binding (walk innermost -> enclosing -> module), while a nested-function local import does NOT leak to its enclosing function, and a `nonlocal`/`global`-declared name is redirected to the correct scope; when an enclosing function binds the name ambiguously -> NO edge (fail closed).
- Y1: when a call's position relative to a function-local binding can't be established (branchy control flow) -> NO edge (fail closed).

<!-- BEGIN:description -->
Extend the T2 bindings into a scope-aware model (M1): a file-wide flat map leaks a function-local import into other callers and cannot represent module-level rebinding. A TWO-LEVEL (module/function) model is INSUFFICIENT (F5): Python resolves names through the LEXICAL CLOSURE CHAIN -- the enclosing-function scopes between a nested function and the module -- so model bindings as a closure chain (innermost function -> each enclosing function -> module), HONORING `global`/`nonlocal` declarations (which redirect a name to the module / nearest-enclosing scope). The resolver consults a caller function's local bindings, then each enclosing function scope, then module-level. A function-local import must NEVER leak to a sibling; nested-function locals must not leak to the enclosing scope. A name whose applicable scope holds a competing binding fails closed (reuses the M1 rule from T2); when an enclosing function binds the name in a way the chain cannot resolve unambiguously, fail closed (F5). Y1 (function-local import ordering): a function-local import binds its name for the WHOLE function body (Python UnboundLocalError semantics); track binding AND call positions so a call BEFORE a function-local import emits NO edge -- a POISON/TOMBSTONE that must NOT fall through to the module scope (F8) -- and only calls AFTER it resolve; uncertain control-flow ordering fails closed. TDD RED->GREEN. Domain: code.
