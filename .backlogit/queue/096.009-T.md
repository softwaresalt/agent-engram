- Function-local `from x import f` is visible inside its own function.
- M1: the SAME call site in a sibling function lacking the import gets NO binding (no leak).
- A module-level import is visible in all functions.
- A nested-function local import does not leak to its enclosing function.
- cargo test --test unit_python_canonical green; clippy --all-targets clean; fmt clean.

<!-- BEGIN:description -->
Extend the T2 bindings into a scope-aware model (M1): a file-wide flat map leaks a function-local import into other callers and cannot represent module-level rebinding. Model bindings at two scopes -- module-level (apply to every function) and per-function-local (apply only within that function) -- so the resolver consults a caller function's local bindings first, then module-level. A function-local import must NEVER leak to a sibling; nested-function locals must not leak to the enclosing scope. A name whose applicable scope holds a competing binding fails closed (reuses the M1 rule from T2). TDD RED->GREEN. Domain: code.
<!-- END:description -->
