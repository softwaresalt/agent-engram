<!-- BEGIN:acceptance-criteria -->
- Function-local `from x import f` is visible for a call AFTER it; but a call BEFORE the function-local import (`def g(): f(); from x import f`) gets NO binding/edge -- fail closed (Y1: `f` is function-local for the whole body, UnboundLocalError at that call).
- M1: the SAME call site in a sibling function lacking the import gets NO binding (no leak).
- A module-level import is visible in all functions AND a nested-function local import does not leak to its enclosing function.
- Y1: when a call's position relative to a function-local binding can't be established (branchy control flow) -> NO edge (fail closed).
- cargo test --test unit_python_canonical green; clippy --all-targets clean; fmt clean.
<!-- END:acceptance-criteria -->

<!-- BEGIN:description -->
Extend the T2 bindings into a scope-aware model (M1): a file-wide flat map leaks a function-local import into other callers and cannot represent module-level rebinding. Model bindings at two scopes -- module-level (apply to every function) and per-function-local (apply only within that function) -- so the resolver consults a caller function's local bindings first, then module-level. A function-local import must NEVER leak to a sibling; nested-function locals must not leak to the enclosing scope. A name whose applicable scope holds a competing binding fails closed (reuses the M1 rule from T2). Y1 (function-local import ordering): a function-local import binds its name for the WHOLE function body (Python UnboundLocalError semantics); track binding AND call positions so a call BEFORE a function-local import emits NO edge (fail closed), and only calls AFTER it resolve; uncertain control-flow ordering fails closed. TDD RED->GREEN. Domain: code.
<!-- END:description -->
