Wire the Terminal arm into ShimHandler::forwarding_endpoint (src/shim/transport.rs). Under the EXISTING recovery_lock, match probe_health: Ready clears the cooldown, publishes StartupOutcome::Ready and forwards; Transient sets last_failure = now and returns EndpointResolutionError::Recoverable; Terminal publishes StartupOutcome::Degraded { ProtocolIncompatible, reason } on startup_tx and returns EndpointResolutionError::Permanent. Publishing Degraded LATCHES the session: every later forwarding_endpoint short-circuits on the Degraded arm before reaching the probe, so no further probes are issued and the terminal answer is stable and idempotent. Taking the latch under recovery_lock is required so a racing request cannot fire a second probe before the watch value propagates. Update degraded_call_tool_result so terminal outcomes carry engram_code 15005, failure_class protocol_incompatible, recoverable false, and NO retry_after_ms key.
