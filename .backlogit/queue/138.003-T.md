Additive failure-class taxonomy change, split from the shim logic because it crosses a different blast radius: documented process exit codes (124-F U5) and the durable startup-failure record schema. Add ShimFailureClass::ProtocolIncompatible with as_str() = protocol_incompatible, wire_code() = SHIM_PROTOCOL_INCOMPATIBLE = 15005, exit_code() = 14, and a fixed variable-free record_message(). readiness_timeout would misreport a protocol mismatch and transport_failure would misattribute a successful transport round trip, so neither is reusable. No existing discriminant, wire code, or exit code changes value; the exhaustive matches in exit_code/as_str/wire_code/record_message give compile-time completeness. This task carries a VETO-capable compat check.
