Plan unit F38 - stable error codes and domain error envelope. Reserve the typed refusal and availability codes plus structured detail fields in `src/errors/codes.rs` and `src/errors/mod.rs`, so every refusal and activation-error producer emits a named, stable code instead of minting a local ad-hoc error.

F38 is a graph root and a foundation unit. F11, F17, F20, F21, F44 and F45 must consume its named codes and typed envelope rather than define their own.

Execution posture: test-first contract definition.

<!-- BEGIN:acceptance-criteria -->
- Typed refusal codes exist for read-server write/control refusal, direct-sync refusal, and workspace-retarget refusal.
- Typed availability codes exist for generation-not-yet-activated, activation-deadline-exceeded, and transient-activation-failure.
- Each code carries structured detail fields rather than a free-text message only.
- Codes are stable identifiers, suitable for assertion by CLI, MCP and IPC contract tests.
- No consumer unit mints a local error where a reserved code applies.
