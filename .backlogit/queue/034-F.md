# Add SQL file indexing via tree-sitter-sequel

<!-- SECTION:DESCRIPTION:BEGIN -->
## Description

Add SQL file parsing to the code graph so `.sql` files are indexed during workspace sync. Uses `tree-sitter-sequel 0.3` (ABI 15, compatible with workspace tree-sitter 0.25.x). Follows the existing swift.rs parser pattern exactly.

Symbol mapping:
- CREATE TABLE / CREATE VIEW → `ExtractedSymbol::Class`
- CREATE FUNCTION / CREATE PROCEDURE → `ExtractedSymbol::Function`
- INSERT INTO / SELECT FROM → `ExtractedEdge::References` (new variant)

5 implementation units: dependency + enum wiring, core tests, secondary tests, extraction logic, code_graph wiring + integration test.
