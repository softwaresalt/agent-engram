## Scope

Create the foundational CLI module:
- `src/cli/mod.rs` — module root with `pub(crate) async fn run()` entry point
- `src/cli/flags.rs` — `GlobalFlags` clap struct: --workspace, --id, --json, --format, --quiet
- `src/cli/output.rs` — `OutputFormatter` producing JSON-RPC 2.0 envelopes and text mode
- Add `pub mod cli;` to `src/lib.rs`

## Acceptance Criteria

- `GlobalFlags` parses all documented flags via clap derive
- `OutputFormatter::success(id, result)` produces valid JSON-RPC 2.0: `{"jsonrpc":"2.0","id":<id>,"result":{...}}`
- `OutputFormatter::error(id, code, message, data)` produces JSON-RPC error envelope
- Text mode produces human-readable summary (non-JSON)
- Unit tests pass for all formatter paths

## Execution Posture

Test-first: write unit tests for OutputFormatter, then implement.

## Dependencies

None (foundation for all other tasks)
