HEARTBEAT LIFECYCLE VIA AN OUTER ASYNC FINALIZER. A periodic heartbeat naming the currently-executing phase is required so an in-progress stall is externally observable. Its lifecycle is its own leaf because a naively spawned periodic task outlives its parent and writes heartbeats for a startup that already finished, producing diagnostics that are ACTIVELY MISLEADING during exactly the incident they exist to explain (risk H9).

AC1 (OUTER ASYNC FINALIZER, NOT AWAIT-IN-DROP, NON-NEGOTIABLE): the heartbeat handle is owned by an OUTER ASYNC SCOPE that runs an explicit async finalizer on EVERY exit path - success, error, early ? return, and watchdog termination. Revision 3 REMOVES the impossible await-in-Drop contract: Drop is synchronous and CANNOT await a task join, so a Drop-based cancel-and-join is unimplementable as written. A synchronous drop guard MAY still be used to REQUEST cancellation, but the JOIN happens in the outer async finalizer.
AC2 (CANCEL AND JOIN BEFORE THE TERMINAL RECORD): the terminal record is written ONLY AFTER the heartbeat task has been cancelled AND JOINED TO COMPLETION. Cancellation alone is asynchronous: a heartbeat already inside its write can still land AFTER the terminal record. A test forces a heartbeat write to be in flight at terminal time and asserts the ordering holds.
AC3 (NO POST-TERMINAL HEARTBEAT ON ANY PATH): an orphan-task regression test asserts no heartbeat record is emitted after the terminal phase record on the success, error, early-return, and watchdog-termination paths.
AC4 (ATOMIC PHASE-PLUS-TERMINAL PUBLICATION): the current phase and the terminal flag are published as ONE operation through an explicitly synchronized cell, so no reader can observe a terminal-but-unset state. The cell is safe across the spawn_blocking boundary - the writer is a blocking thread, the reader is the async heartbeat - and does NOT require the blocking closure to become async. Any equivalent proven synchronization protocol satisfies this; no specific internal type is mandated.
AC5 (COARSE INTERVAL): the heartbeat interval is coarse relative to phase durations so the instrumentation cannot itself slow startup (risk H8).
