Generate the parity surface matrix from the F19 descriptor declarations: for each descriptor, produce the exact set of (surface, expected outcome) pairs it declares, so the harness never hand-asserts a surface.

<!-- BEGIN:acceptance-criteria -->
- The matrix is derived programmatically from descriptor declarations.
- Every descriptor appears in the matrix exactly once.
- A descriptor declaring one surface produces exactly one surface row.
- Adding a descriptor changes the matrix with no manual harness edit.
- No hand-maintained surface list remains in the harness.
<!-- END:acceptance-criteria -->
