## Scope

Create `src/cli/commands/lifecycle.rs` with 4 handlers:

| CLI Command | MCP Method | Params |
|---|---|---|
| `engram bind [path]` | `set_workspace` | `{"path":"<resolved>"}` (defaults to cwd) |
| `engram daemon-status` | `get_daemon_status` | `{}` |
| `engram workspace-status` | `get_workspace_status` | `{}` |
| `engram flush` | `flush_state` | `{}` |

Use `#[command(name = "daemon-status")]` and `#[command(name = "workspace-status")]`
to generate hyphenated names (avoids conflict with existing `Command::Daemon` variant).

## Acceptance Criteria

- All 4 commands construct correct IpcRequest with proper method and params
- `bind` without path argument defaults to current working directory
- `daemon-status` does NOT conflict with `engram daemon --workspace <path>`
- Contract tests verify exact IpcRequest construction for each command
