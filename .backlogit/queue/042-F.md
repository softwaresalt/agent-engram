## Summary

Full CLI parity for all MCP tool operations. Every MCP tool exposed by the engram
daemon gets a corresponding CLI subcommand. Output is JSON-RPC 2.0 on stdout
(identical in shape to MCP responses).

**Purposes:**
1. Startup preloading in `start.ps1` before Copilot launches — avoids MCP timeout
2. Agent fallback — if MCP transport fails, agents exec the CLI binary as subprocess

**Architecture:** CLI → IPC → daemon (reuses shim transport). Manifest command reads
compile-time catalog directly (no daemon needed).

## Acceptance Criteria

- All 18 default MCP tools are callable via CLI subcommands
- `engram manifest` outputs tools/list JSON-RPC response without requiring daemon
- JSON-RPC 2.0 output format on stdout when `--json` or non-TTY
- Human-readable output on TTY or when `--format=text`
- Exit codes: 0 (success), 1 (tool error), 2 (CLI error)
- `--id <value>` echoes caller-supplied request ID
- Existing commands (shim, daemon, install, etc.) unaffected
- Agent fallback protocol documented in agent-engram.instructions.md
