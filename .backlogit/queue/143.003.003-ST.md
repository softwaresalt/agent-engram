BOUNDED SHIM BACKOFF WITH TERMINAL STOP. CONSUMES the durable counter owned by 143.003.004-ST and 143.003.007-ST; it does NOT define its own counter.

A self-terminating daemon plus an eager shim is a respawn loop that re-pays the full cold-start cost forever and destroys partial progress each cycle - potentially worse than the current hang (risk H10).

AC1 (TERMINAL STOP): after 3 CONSECUTIVE watchdog-classified terminations the shim STOPS RESPAWNING and returns a terminal error to the caller rather than retrying.
AC2 (BOUNDED EXPONENTIAL BACKOFF): backoff is exponential and bounded. A test asserts a TERMINATING respawn sequence with no unbounded loop on ANY path.
AC3 (FAIL CLOSED ON UNREADABLE LEDGER): an unreadable, corrupt, or unknown-version ledger is treated as AT LIMIT (stop respawning), NOT as count zero. A test injects each of the three failure shapes.
AC4 (CLASS-GATED COUNTING): only terminations carrying the 143.004.002-ST watchdog failure class drive the policy; a crash, an operator kill, or an unrelated exit does not trigger backoff or the terminal stop.

Files: src/shim/mod.rs plus tests. Single domain: code with its own tests.
