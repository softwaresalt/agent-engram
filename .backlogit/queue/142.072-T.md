Scope: new root module `engram::cli::commands::preflight` (not in the IPC-only `lifecycle.rs`), four functions and one constant:
- `resolve_supervisor(engram_exe)`: canonicalize, parent, join `engram-indexer{EXE_SUFFIX}`; must be a regular file; no PATH, env, or `C:\Tools` lookup.
- `run_relay(supervisor, workspace, timeout_ms, engram_exe) -> RelayOutcome`: spawns `preflight --workspace <W> --timeout-ms <T> --engram <E>` (stdin null, stdout piped, stderr inherited); bound `T + RELAY_GRACE_MS (2000)` via `checked_add` (overflow => `Failed`/`Build`, cause `relay_deadline`, nothing spawned); bounded child I/O (4 KiB + 1 cap, `try_wait` loop, 250 ms post-exit drain, detached reader never joined), keyed on the supervisor's EXIT; expiry => kill + wait, `relay_deadline`; > 4 KiB => `relay_oversize` (kill + reap if running; <= 4 KiB echoed to stderr); reader I/O error => `relay_read`.
- `normalize_verdict(stdout: &[u8], exit_code: Option<i32>) -> (&'static str, i32)`: strips exactly one trailing `\n`/`\r\n`; exactly one line from the closed set; `Succeeded`/0 only when the line is `Succeeded` AND `Some(0)`; the child's well-formed `Failed` line/1 only for `Some(n != 0)`; everything else `Failed`/`Build`/1 with non-conforming bytes (<= 4 KiB) to stderr; raw child exit code never relayed.
- `pub const RELAY_STAGES: [&str; 7]`: the relay's closed set of `Failed` lines, one full line `{"state":"Failed","stage":"<Stage>"}` per stage that `stage_name` can return (the seven stages of `142.069-T`). For a child's `Failed` line, `normalize_verdict` returns the element it equals byte for byte (after stripping one trailing newline), so its result stays `&'static str`; its own `Failed`/`Build` result is the `Build` element. `normalize_verdict` uses no other stage or line list (plan A21, A22 rev. R14). If `stage_name` returns a stage count other than seven, the array length follows it.
- `run_preflight(workspace, timeout_ms) -> i32`: `current_exe()` -> `resolve_supervisor` -> `run_relay`; prints the one normalized line to stdout and ONE relay stderr line (own prefix, see acceptance); no `?` toward `main`.
