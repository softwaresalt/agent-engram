Plan unit F45 - generation observability without deletion. Extend `src/tools/lifecycle.rs` to report the active, published and last-failed revision, branch divergence, retained runtime copies and contexts, activation deadlines, and generation disk usage.

This unit REPORTS only. It performs no deletion and no cleanup - non-destructive generation handling is an explicit constraint of this release.

Execution posture: test-first.

<!-- BEGIN:acceptance-criteria -->
- The report exposes active revision, published revision, and last-failed revision.
- Branch divergence between the served generation and the current branch is reported.
- Retained runtime copies and retained contexts are reported with counts.
- Activation deadlines are reported.
- Generation disk usage is reported.
- NO deletion, pruning, or cleanup is performed by this unit.
- Reported values come from the F17 activation service state, not from a fresh filesystem scan on the read path.
- `tests/integration/generation_observability_test.rs` asserts each reported field and asserts nothing is deleted.
<!-- END:acceptance-criteria -->
