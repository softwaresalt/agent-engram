## DRY refactor — extract resolve_reference_target helper

## Description

Extract the duplicated reference-resolution logic into a single method on
`CodeGraphQueries`. The logic currently exists in three places:

1. `src/services/code_graph.rs:411-431` (index_workspace path)
2. `src/services/code_graph.rs:931-951` (sync_workspace path)
3. `src/db/queries.rs:887-894` (reresolve_references_edges)

Create `pub(crate) async fn resolve_reference_target(&self, qualified_name: &str)
-> Result<Option<String>, EngramError>` on `CodeGraphQueries` and replace all
three inline copies with calls to this method.

## Scope

- `src/db/queries.rs` — add `resolve_reference_target` method
- `src/services/code_graph.rs` — replace inline resolution at both sites
- `tests/contract/references_edge_test.rs` — new unit test for the helper

## Acceptance Criteria

- `resolve_reference_target` resolves exact name, schema-qualified fallback
- Inline resolution logic removed from both `code_graph.rs` sites
- `reresolve_references_edges` uses the helper (or batch equivalent)
- Unit test covers: exact match, schema-qualified fallback, no-match → None
- All existing tests pass (behavior-preserving refactor)
- `cargo test` and `cargo clippy` pass

## Execution Posture

exist), extract helper (green), replace inline copies, confirm full suite green.
