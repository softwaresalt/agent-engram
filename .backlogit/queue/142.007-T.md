Plan unit F03 - immutable daemon mode in application state. Require the resolved `DaemonMode` at `AppState` construction in `src/server/state.rs` and expose no setter, so the mode cannot be mutated after startup and no code path can observe two different modes within one process lifetime.

Execution posture: test-first.

<!-- BEGIN:acceptance-criteria -->
- `AppState` requires the mode at construction; there is no default-mode escape hatch.
- No setter, no interior-mutability path, and no reassignment of the mode exists.
- The mode is readable by every consumer that needs it.
- `tests/unit/app_state_mode_test.rs` asserts construction requires the mode and that no mutation API is exposed.
- Managed-mode behavior is unchanged.
<!-- END:acceptance-criteria -->
