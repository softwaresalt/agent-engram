Add integration tests using the compiled binary (`Command::new(env!("CARGO_BIN_EXE_engram"))`) to verify the dispatch layer respects `--workspace`. Library-level tests are supplementary — the binary tests are the critical regression coverage since the bug is in the dispatch layer, not the installer library.

## Scope

- `tests/integration/installer_test.rs` — new test functions

## Test Scenarios

1. `engram install --workspace <target>` creates `.engram/` in target, not in cwd
2. `engram update --workspace <target>` updates target (pre-install first)
3. `engram uninstall --workspace <target>` removes from target, not cwd

## Notes

- Include `.env_remove("ENGRAM_DATA_DIR")` per compound learning
- Use `tempfile::tempdir()` for both target and cwd directories
- Assert `.engram/` exists in target AND does not exist in cwd
