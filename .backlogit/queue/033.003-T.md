# Create .mcp.json.example and Fix Local MCP Configuration

## Description

Create a committed `.mcp.json.example` template showing the correct MCP server
configuration structure with placeholder paths and no secrets. Fix the local
(gitignored) `.mcp.json` to use correct workspace paths and externalize the
Tavily API key.

Source: stash `stash-002-mcp-json-paths`, `stash-003-tavily-key`.

## Scope

- `.mcp.json.example` (new file, committed)
- `.mcp.json` (local only, untracked — not committed)

## Approach

Direct edit. Execution posture: config domain.

`.mcp.json.example` template:
- All 7 server entries (engram, backlogit, context7, microsoft-docs,
  agent-intercom, tavily, github)
- Placeholder paths: `<WORKSPACE_ROOT>` instead of hardcoded absolute paths
- `${TAVILY_API_KEY}` env var reference instead of plaintext key

Local `.mcp.json` fixes:
- `ENGRAM_WORKSPACE`: `D:\\GitHub\\agent-engram` → `D:\\Source\\GitHub\\agent-engram`
- `BACKLOGIT_WORKSPACE`: `D:\\GitHub\\agent-engram` → `D:\\Source\\GitHub\\agent-engram`
- Tavily URL: replace hardcoded `tvly-dev-*` key with env var pattern

## Acceptance Criteria

- `.mcp.json.example` is tracked: `git ls-files .mcp.json.example` returns the file
- `.mcp.json.example` contains no API keys: `Select-String -Path ".mcp.json.example" -Pattern "tvly-"` finds nothing
- `.mcp.json.example` contains no hardcoded absolute paths: no `D:\\` or `C:\\` strings
- Local `.mcp.json` workspace paths contain `D:\\Source\\GitHub\\agent-engram`
- Local MCP servers (engram, backlogit) are reachable after config fix
- Tavily MCP server is reachable with `TAVILY_API_KEY` env var set
