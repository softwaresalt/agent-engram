Plan unit NEW-2 (plan revision 5, section "NEW-2: Supervisor invocation contract and dispatch function"). Lineage: stash 03AA00A8 (D2-A, Amendment 1). Execution posture: test-first.

Scope: new supervisor module `engram_indexer::preflight_invocation`:
- `pub fn parse_invocation(args: impl IntoIterator<Item = OsString>) -> Result<Invocation, UsageError>` (strict): required `--workspace <PATH>` (valid UTF-8, existing directory, kept exactly as given: no canonicalization, no `.git` check; invariant 9), required `--timeout-ms <u64>`, required `--engram <PATH>` (absolute, canonicalized, existing regular file); rejects duplicate flags, unknown flags, positional extras, and a flag token used as a value.
- `pub fn deadline_from(now: Instant, timeout_ms: u64) -> Result<Instant, UsageError>` via `checked_add`.
- `pub fn main_with<V, F>(args, make: F) -> PreflightOutput` with `F: FnOnce(&Invocation, Instant) -> Result<(V, String), SetupError>`; returns `PreflightOutput { stdout: Option<&'static str>, stderr: String, exit_code: u8 }`; usage error => `stdout: None`, exit 2; setup error => `Failed`/`Build`, exit 1; otherwise `run`; `make` runs only after the deadline is computed and must not mutate the filesystem.
- Exactly one structured stderr line: `engram-preflight stage=<Stage|none> cause=<ok|usage|setup|deadline|verifier> elapsed_ms=<n>`, never containing env values or probe payloads.

Owned files (production): `crates/engram-indexer/src/preflight_invocation.rs` (new); `crates/engram-indexer/src/lib.rs` (one line).
Harness (RED first): `tests/integration/preflight_invocation_test.rs` + `[[test]] name = "integration_preflight_invocation"`; `#[path]` includes `preflight.rs`, `preflight_verdict.rs`, `preflight_invocation.rs` with scoped `#[allow(dead_code)]`.

Test scenarios (3): (1) valid spaced invocation; (2) strict-parser table; (3) `main_with` with a mock factory.
