Plan unit F16 - mode-agnostic read request context. Add managed and generation-backed constructors for `ReadRequestContext` in `src/server/state.rs`, so every read path consumes one context type regardless of daemon mode. Managed mode constructs it from current behavior; ReadServer mode constructs it from the `GenerationReadContext` produced by F17.

Execution posture: test-first.

<!-- BEGIN:acceptance-criteria -->
- `ReadRequestContext` has a managed constructor and a generation-backed constructor.
- Read handlers consume one context type in both modes; no mode branching leaks into handlers.
- The context is held as an `Arc` and its lifetime keeps the underlying generation open.
- Managed-mode behavior is unchanged.
- `tests/unit/read_request_context_test.rs` covers both constructors and Arc lifetime.
<!-- END:acceptance-criteria -->
