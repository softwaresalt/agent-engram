## Scope

Create `src/cli/runner.rs` — the IPC call wrapper:
1. Resolve workspace path from GlobalFlags or cwd
2. Resolve IPC endpoint via `daemon::ipc_server::ipc_endpoint()`
3. Ensure daemon is running via `shim::lifecycle` module
4. Build `IpcRequest` with method + params
5. Call `ipc_client::send_request()` with timeout
6. Map `IpcResponse` to `(Value, ExitCode)`:
   - result present → exit 0
   - error present → exit 1
   - connection/invocation failure → exit 2

## Acceptance Criteria

- `run_tool(method, params, flags)` returns `(Value, ExitCode)` tuple
- IPC success → exit code 0 + result value passed to OutputFormatter
- IPC tool error → exit code 1 + error value
- Connection failure or bad invocation → exit code 2 + stderr message
- Unit tests verify all three exit code paths

## Execution Posture

Test-first: write unit tests for exit code mapping, then implement.
