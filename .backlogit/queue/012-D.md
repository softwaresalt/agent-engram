# Engram usage-telemetry EMIT (ingest->emit pivot)

## Problem Frame

<!-- BEGIN:problem-frame -->
Operator pivoted engram telemetry from INGEST/sink to EMIT/source. Must emit per-call usage telemetry to append-only JSONL for autoharness. Grounding revealed a per-call usage.jsonl emitter ALREADY EXISTS (src/services/metrics.rs -> .engram/metrics/{branch}/usage.jsonl); stash premise 'no existing emission' is stale. Real gaps: correlation_id (field+param), latency_ms, explicit workspace, coarse params, schema_version, rotation, config path-override, and choke-point coverage for set_workspace/sync_workspace/index_workspace.
<!-- END:problem-frame -->
