Plan unit PRE-2 (plan revision 5, section "PRE-2: Generation store opening and candidate publish facade"; the plan is authoritative). Lineage: stash 49809128 (D4-A). Execution posture: test-first.

Scope: three public functions in `candidate_build.rs`:
- `open_generation_store(layout, create)`: rejects a symlinked/reparse-point `<workspace>/.engram`, `generations_root`, or `runtime_root` (`symlink_metadata`) with `ContainmentEscape`; `create_dir_all(generations_root)` only when `create`; `GenerationStore::new` must yield a root inside the workspace, checked ONLY through the private one-comparator helper `within_root(child, root)` = `normalize_canonical(std::fs::canonicalize(child))` starts_with `normalize_canonical(std::fs::canonicalize(root))`; missing root with `create == false` is `StoreAbsent` and creates nothing.
- `current_published_revision(store)`: delegates to `read_current_manifest_revision` (made `pub(crate)` in `publish.rs`, logic unchanged); absent manifest = revision 0; unreadable/unparsable = typed error, never 0.
- `publish_sealed_candidate(layout, store, sealed, producer)`: revision `current + 1` via `checked_add`, `SUPPORTED_MANIFEST_SCHEMA_VERSION`, `BranchIdentity::new(&layout.branch, None)`, `WorkspaceIdentity::new(&layout.workspace_id)`, the sealed inventory, `GenerationProvenance::new(producer, Utc::now())`; publishes ONLY via `publish_generation_manifest`; never retries.

Owned files (production): `src/services/generations/candidate_build.rs`; `src/services/generations/publish.rs` (visibility only).
Harness (RED first): `tests/integration/candidate_generation_publish_test.rs` + `[[test]] name = "integration_candidate_generation_publish"`.

Test scenarios (3): (1) first publish and activation; (2) second publish and store containment; (3) corrupt manifest.
