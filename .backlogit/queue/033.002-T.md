# Add P-010 Branch Creation Enforcement Policy

## Description

Add policy P-010 "Feature Branch Creation Before First Commit" to
`.github/policies/workflow-policies.md`. This addresses the process violation
documented in stash `4CE7A279` where shipment 007-S was committed directly to
`main` without a feature branch or PR.

Also add a compliance note to the P-009 section confirming that
`allow_rebase_merge` has been disabled in GitHub settings.

Source: stash `4CE7A279`, `stash-001-rebase-merge`.

## Scope

- `.github/policies/workflow-policies.md` — add P-010, update P-009, update
  amendment log

## Approach

Direct edit. Execution posture: docs/policy domain.

P-010 fields:
- **Applies to**: `ship`
- **Gate point**: Ship Step 1 pre-flight
- **Statement**: Ship MUST verify it is on a dedicated feature branch before
  creating any commit. Direct commits to `main` are forbidden.
- **Precondition**: `git branch --show-current` ≠ `main`
- **Violation action**: Halt, create feature branch, broadcast P-005

## Acceptance Criteria

- `workflow-policies.md` contains P-010 with Applies To, Gate Point, Statement,
  Precondition, Postcondition, and Violation Action fields
- P-009 section notes rebase merge setting is disabled
- Amendment log updated with version bump
- `Select-String -Path ".github/policies/workflow-policies.md" -Pattern "P-010"` finds the policy
