New src/services/parsing/python_canonical/ module (module_path.rs + mod.rs). python_module_path_for_file(rel_path, layout: &PackageLayout) -> Option<String>, where PackageLayout carries package/source-root metadata: which ancestor dirs are provable regular packages (contain __init__.py) and any declared source roots (e.g. src/). M5: a pure rel_path transform is INSUFFICIENT because src/pkg/mod.py and an implicit PEP 420 namespace/pkg/mod.py contain only valid identifiers, so a naive transform would mint src.pkg.mod / namespace.pkg.mod and could create a false canonical path. Resolve foo/bar.py -> Some("foo.bar") ONLY when every ancestor dir is a provable regular package, or a declared source-root leading segment is stripped (src/pkg/mod.py -> pkg.mod). Fail closed (None) for: __init__.py; any non-identifier segment; an implicit namespace package (ancestor dir without __init__.py that is not a declared source root); an undeclared/ambiguous source root; non-.py paths. Conservative default: when the layout cannot be proven, REJECT (fail closed). None => the caller writes "" (never a match target, D4). TDD RED->GREEN. Single skill domain: code.
