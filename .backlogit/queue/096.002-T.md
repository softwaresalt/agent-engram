The position (byte/line order) is REQUIRED by T5c's order-aware winner anchor (F1) and the F4 star invalidator; every binding record carries it (F14). from N import name -> name=(N.name, FromImportSymbol, pos); from N import name as p -> p=(N.name, FromImportSymbol, pos); import a.b as c -> c=(a.b, ModuleImport, pos); import a.b -> a=(a, ModuleImport, pos). R2: the kind lets T5b tell a module receiver (import pkg -> pkg.func()) from an imported symbol (from pkg import parse -> parse() / parse.tokenize()) so a from-import is never mis-resolved as a module. Fail closed (NO binding) for relative imports (from . import x / leading-dot) and importlib/__import__/dynamic; relative imports AND control-flow-conditional/`try`-guarded imports (if/else/try/except/while, not unconditionally executed at module scope) are ADDITIONALLY recorded as POSITIONED AMBIGUITY MARKERS (Anchor C T-b/T-c) -- not firm bindings -- so T5a treats a same-file same-name def as CONTESTED and never mints a direct M.f edge (this makes T5b's typed no-target reason reachable). F4: a module-scope `from N import *` star import mints NO binding for any name, but IS recorded as a POSITIONED ORDER-AWARE INVALIDATOR MARKER -- T5c fails closed when a star occurs AFTER the winning binding (`from bar import parse; from n import *; parse()` -> NO edge, the later star may rebind parse); a star BEFORE the winner does not invalidate it. M1: a competing/duplicate binding for the same local name within a scope is marked ambiguous -> NO binding, and recorded as a positioned AMBIGUITY MARKER (Anchor C T-b) so T5a contests a same-file same-name def; a flat last-writer-wins HashMap is FORBIDDEN. This covers BOTH `import p` + `from q import p` AND two from-imports of one name (`from a import f; from b import f`). C8-1 (consistency with the frozen C7-1 call-site last-binding rule): duplicate same-name imports at a scope are NOT ordered-disambiguated in v1 -- T2 fails closed (no binding) so T5b derives no canonical target and drops; the F3 legacy fallback also drops (name non-unique); ordered-import-history is a documented v1 non-goal. The call-site last-binding-wins rule (T5b) resolves def-vs-SINGLE-import + rebinds, never import-vs-import. Function-vs-module scope isolation is handled by T2b (096.009-T).
