## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add the atomic snapshot API to `AppState` that captures workspace binding and
config in a single operation, eliminating the TOCTOU window where policy could
change between check and execution.

**File:** `src/server/state.rs`

**Changes:**

1. Add `DispatchSnapshot` struct with `workspace: WorkspaceSnapshot` and
   `config: WorkspaceConfig` fields. Derive `Clone, Debug`.

2. Add `snapshot_dispatch_context()` async method to `AppState` that acquires
   read locks on both `active_workspace` and `workspace_config` simultaneously,
   clones both, and returns `Option<DispatchSnapshot>`. Returns `None` when no
   workspace is bound. Uses `WorkspaceConfig::default()` when config is `None`
   (policy disabled by default).

**Execution posture:** test-first — contract test harness exists in red phase at
`tests/contract/atomic_policy_snapshot_test.rs` (tests C018-01 through C018-05).

**Granularity:** 1 file, 2 items (struct + method), 5 test scenarios
<!-- SECTION:DESCRIPTION:END -->
