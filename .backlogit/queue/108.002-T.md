Source stash 6487F516 (medium bug, PR #301 follow-up). `index_workspace_impl` currently loads and clears the previous canonical-workspace snapshot, records transient per-file read/parse failures in `IndexResult.errors`, then unconditionally publishes the current topology. A topology-forced descendant that fails can retain its old canonical identity while the retry obligation is erased; the next ordinary index sees no topology delta and hash-skips the restored byte-identical file. Implement clean-pass snapshot certification: publish current only when `result.errors` is empty; otherwise restore the loaded previous snapshot or leave absent when none existed. No retry relation, schema, public failpoint, CLI/MCP, or response-contract change.

<!-- BEGIN:acceptance-criteria -->
- RED first, portable and sleep-free: initial ordinary index of valid `p/mod.py` without `p/__init__.py`; add the package marker, replace the descendant with invalid UTF-8, and assert the ordinary index reports the targeted read error.
- The partial run retains the previous canonical-workspace snapshot (or leaves it absent in the no-prior variant) and does not advance Python/code-graph extraction markers. It never publishes the current topology.
- Restore the exact original valid descendant bytes and run ordinary index: despite the hash matching the first index, the preserved old/absent snapshot forces parsing and canonical identity becomes `p.mod.cf`.
- One further clean ordinary index publishes current topology and hash-skips the unchanged descendant, proving no permanent reparse loop.
- Snapshot restore/publish failure propagates as `EngramError`; no public API, schema, feature flag, CLI/MCP field, or wire semantic changes.
<!-- END:acceptance-criteria -->

<!-- BEGIN:implementation-notes -->
Single full-index canonical-persistence width; target <=100 minutes and <=2 files. Use the existing loaded `previous_canonical_workspace`, `result.errors`, `clear_index_canonical_workspace_snapshot`, and `replace_index_canonical_workspace_snapshot`. Prefer an inline/private finalization branch; deterministic invalid UTF-8 exercises the actual read-error path without a test seam. Preserve all post-pass, dangling-sweep, and marker ordering. Dark-mode stop: return blocked if deterministic coverage requires a public seam, exceeds four scenarios/two files, or exposes broader topology state.
