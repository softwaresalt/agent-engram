Create `src/cli/direct.rs` — a lightweight runner for CLI-direct (daemonless) indexing operations.\n\n## Implementation\n\n1. Add a new module `src/cli/direct.rs` with a `run_direct()` function\n2. `run_direct()` accepts `(method, ws_path, formatter)` and:\n   - Resolves workspace root via `canonicalize_workspace()`\n   - Acquires `DaemonLock::acquire(workspace)` — exit with code 2 and clear error if `AlreadyHeld`\n   - Calls `resolve_data_dir()`, `resolve_git_branch()`, `parse_config()`\n   - Dispatches to `index_workspace()` or `sync_workspace()` from the services layer\n   - Formats the result via `OutputFormatter` (JSON or text)\n   - Drops `DaemonLock` on exit (automatic via RAII)\n3. Register `mod direct;` in `src/cli/mod.rs`\n\n## Acceptance Criteria\n\n- `run_direct()` compiles and can be called from the CLI subcommand handlers\n- `DaemonLock` prevents concurrent operation with daemon\n- Config is loaded via `parse_config()` (not from `AppState`)\n- `cargo test` passes\n- `cargo clippy -- -D warnings -D clippy::pedantic` clean\n\n## Scope\n\n- `src/cli/direct.rs` (new file)\n- `src/cli/mod.rs` (add `pub mod direct;`)
