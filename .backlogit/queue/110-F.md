High-priority production prerequisite for blocked 103-S and 108-F. Windows sysinfo 0.30.13 can open a terminated process object on the first refresh, so fresh-System PID checks report a killed/reaped daemon live and route stale recovery into ShutdownTimeout. Preserve the existing additive {pid,start_time_unix} identity, require a same-System active-state refresh, carry full identity through shutdown waiting, and retain endpoint plus OS-lock authority. Reviewed PASS plan: docs/exec-plans/2026-08-02-windows-pid-identity-stale-recovery-plan.md. Scope excludes 103 ordinary-index implementation, Cargo/dependency changes, unsafe code, protocol/schema changes, timeout increases, runner productization, operator-cache action, and extra worktrees.
