Scope: new top-level module `engram::preflight_probe` (synchronous, `std::process` + `std::thread` only; no `serde_json` in any public signature):
- `ProbeRead { cli_args, mcp_tool, mcp_arguments_json }` (all `&'static`), `PREFLIGHT_READ` (`stats` / `get_workspace_statistics` / `{}`), `HEALTH_READ` (`health` / `get_health_report` / `{}`).
- `ProbeReport { accepted, generation_id, data_fingerprint }`, fingerprint `code_files=<n>;functions=<n>;classes=<n>;interfaces=<n>;edges=<n>`.
- `probe_cli_read(engram, workspace, read, deadline)`: spawns ONLY the absolute canonical `engram` as `--workspace <W> --json <cli_args...>`, stdin null, `stderr(Stdio::null())`, bounded child I/O (1 MiB cap) keyed on the CLI child's exit, parses the first JSON line of exit + 250 ms drain; a typed JSON refusal maps to `accepted: false` (never `Exit`).
- `wait_for_generation(engram, workspace, read, expected, deadline)`: re-probes (50 ms doubling to 500 ms) until `generation_id == expected` or deadline, re-probing on `accepted: false`.
- Private `run_bounded` and `parse_report`; `ProbeError` = `Spawn | Deadline | Exit | Oversize | Malformed | Mismatch` (thiserror; static causes only; no `serde_json` payload).
