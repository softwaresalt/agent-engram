U3 from the reviewed 5765BAAB plan. Using the controlled U1 harness, separately time cold startup/model readiness, pre-warmed request dispatch, server completion, response-frame write, and client receipt for daemon `engram index`. Correlate one request ID end to end and determine which phase is outside or exceeds the user deadline. CLI/IPC investigation width only; do not preselect streaming as the fix.

<!-- BEGIN:acceptance-criteria -->
- Cold and pre-warmed invocations are timed as separate phases with binary/revision provenance.
- A short-timeout negative case proves whether the user deadline covers daemon startup and timed `send_request`.
- Server dispatch completion, response-frame write, and client receipt are correlated by request ID.
- The outcome is classified as startup-outside-deadline, synchronous long-op timeout, response write/read failure, a combination, or current non-reproduction.
- The smallest contract surface for any later fix is named without implementing it.
- Every probe is capped at five minutes, at most two equivalent reproductions are attempted, and only owned child processes are cleaned up.
<!-- END:acceptance-criteria -->
