Scope (production file edited: `src/preflight_probe.rs` only, the module `142.067-T` creates): `pub fn probe_mcp_read(engram, workspace, read, deadline) -> Result<ProbeReport, ProbeError>` plus private `run_mcp_session`:
- `mcp_arguments_json` is parsed internally BEFORE spawning; invalid JSON or a non-object => `Malformed` (static cause `mcp_arguments`) and no child is spawned; `serde_json` never appears in the signature.
- Spawns the absolute `engram` as `shim --workspace <W>` with piped stdin/stdout and `stderr(Stdio::null())`; the reader thread sends LINES through `take(cap + 1)` (1 MiB cap).
- Every "await a response line" is a `recv_timeout` sliced to <= 20 ms, interleaved with `try_wait()`; on early shim exit the 250 ms post-exit drain runs once, and a still-missing line is `Exit` (non-JSON => `Malformed`).
- Session: `initialize` + await response; `notifications/initialized` + one `tools/call`; READ the matching `tools/call` response BEFORE closing stdin (142.060-T lesson); drop stdin; `try_wait` loop until exit or deadline (kill + reap on expiry); never wait for stdout EOF; never join the reader.
- Extraction, inline in this task's code: `generation_id` and `data_fingerprint` are the `generation_id` and `data_fingerprint` fields of the tool result's `structuredContent`.

Harness (written by the harness-architect at Step 2): this task's own cases in `tests/integration/preflight_probe_test.rs` (`integration_preflight_probe`, the file `142.067-T` creates).

Test scenarios (3): (1) real daemon; (2) bad output; (3) hangs.
