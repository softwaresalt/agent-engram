Plan unit F50 - typed preflight state machine in the supervisor. Implement `crates/engram-indexer/src/preflight.rs` as a typed state machine carrying ONE deadline and ONE expected generation through:

Build -> Seal -> Publish -> DaemonVerified -> HealthVerified -> CliProbeVerified -> McpProbeVerified -> Succeeded, or a typed Failed.

This supersedes the 118-S Guardrail 4 fail-open behavior: an agent session must not be able to begin with Engram degraded.

Execution posture: test-first. RS4/RS5 adjacent - this unit gates session start, so its failure semantics must be fail-closed.

<!-- BEGIN:acceptance-criteria -->
- The state machine is typed; an invalid transition is unrepresentable rather than a runtime check.
- Exactly one deadline spans the whole sequence; individual stages do not each restart it.
- Exactly one expected generation is carried through every stage.
- Every stage failure produces a typed `Failed` variant naming the stage.
- The machine is FAIL-CLOSED: any failure yields `Failed`, never a degraded `Succeeded`.
- `Succeeded` is reachable only after all seven stages verify.
- `tests/integration/preflight_gate_test.rs` covers success and a failure injected at each stage.
<!-- END:acceptance-criteria -->
