Extend or add a test that exercises the concurrent `connect_db` scenario where both calls would previously race on schema bootstrap. The test should confirm that two parallel `connect_db` calls to the same DB path both succeed without SQLITE_BUSY panics, including the schema bootstrap phase.

## Acceptance Criteria

- Test calls `connect_db` concurrently (e.g., `tokio::join!` or `spawn` + `join`)
- Both calls target the same DB path
- Both calls complete without panic or SQLITE_BUSY error
- Test is placed in `tests/integration/` or extends the existing concurrent test in `src/db/cozo_backend/mod.rs`
- `cargo test --features cozo-backend` passes
