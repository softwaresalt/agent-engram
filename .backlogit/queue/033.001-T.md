# Disable Rebase Merge in GitHub Repository Settings

## Description

Navigate to GitHub Settings → General → Pull Requests and uncheck "Allow rebase
merging." This is a manual operator action required for P-009 compliance.

Source: stash `stash-001-rebase-merge`.

## Scope

- GitHub repository settings UI change only
- No code or file modifications

## Approach

Operator-guided: the Ship agent cannot automate GitHub Settings UI changes. The
agent should prompt the operator to make the change and then verify via the
`gh api` command.

## Acceptance Criteria

- `gh api /repos/softwaresalt/agent-engram --jq '.allow_rebase_merge'` returns `false`
