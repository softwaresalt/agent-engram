Concrete first slice of the 069-F tree-sitter evaluation — a **decision gate, not a grammar build**. Build a differential-evaluation harness that quantifies where the current safe TMDL parser (`crates/powerbi-tmdl-parser::parse_tmdl_document`, `lib.rs:251`, adapted by `src/services/powerbi_tmdl.rs`) drops, truncates, or mis-scopes real-world TMDL structure, and record the correctness delta. Test-first, ~2h, single-width, **NO new dependency, NO grammar**.

## Scope

- Assemble a representative TMDL corpus as inline `r"..."` fixtures continuing the `S-PTM-0x` pattern in `tests/unit/powerbi_extract_tmdl_test.rs` (or committed test fixtures) — **NOT** the uncommitted `tmp/ILSOS-VehicleServices...` dev sample. Cover the high-value constructs: a multi-object `model.tmdl`; block-form `relationships.tmdl` (named `relationship` blocks with `fromColumn:`/`toColumn:`); and complex table files with multiline DAX measures, `partition` blocks with fenced `source = ``` … ``` ` M bodies, `ref`/`annotation`/`lineageTag` lines, and nested member blocks (`hierarchy`/`level`/`role`).
- Run each fixture through `parse_tmdl_document` and assert the produced `TmdlModel` against expected structure; where the parser under-captures, record the specific miss (dropped / truncated / mis-scoped) as a documented, machine-checkable delta (assertions + a summary table in the harness output or test module docs).
- Stay inside the parser crate's `#[cfg(test)]` + `tests/unit/` boundary; add at most one `tests/integration/powerbi_search_ingestion_test.rs` assertion if a miss demonstrably affects ingestion/search.

## Definition of Done (with decision rule)

- Harness runs over the corpus and emits a recorded per-construct correctness delta (pass / miss with the failure mode).
- **Decision rule (baked in):**
  - **Low structural error** (no material mis-parses) → recommend **decline**: close 066.008-T as `decline`, keep hardening the safe parser incrementally, and retire/park 069-F. A grammar is not ROI-positive.
  - **Material structural mis-parses** that are hard to fix incrementally → promote follow-on tasks under **069-F**: (a) grammar sourcing (vendor vs. generate + maintain `grammar.js`), (b) external indentation scanner, (c) grammar ABI pinning + build-fragility mitigation (see `docs/compound/build-errors/tree-sitter-grammar-abi-tsx-dispatch-2026-04-15.md`), (d) parity + regression tests vs. the safe parser on the same corpus.
- Test-first, `S-PTM-2x` naming continues the existing pattern; `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings -D clippy::pedantic`, and `cargo test --all-targets` green.
- Measurement-only: no production parser behavior change is required; crate stays `#![forbid(unsafe_code)]`; **no new dependency and no grammar added** this slice.
