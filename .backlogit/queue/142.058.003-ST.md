Assert every refusal class and the absence of side effects: Write, Control, unsafe lifecycle, direct mutation workflow, and unknown methods must all be refused with the stable F38 code and must leave no trace.

<!-- BEGIN:acceptance-criteria -->
- Write capability calls are refused in ReadServer mode with the stable F38 code.
- Control capability calls (including `_shutdown`) are refused.
- Unsafe lifecycle calls - notably workspace retargeting - are refused.
- Direct mutation workflows are refused and direct operators to `engram-indexer`.
- Unknown methods are refused without activating a generation.
- EVERY refusal case asserts no side effects: no generation change, no workspace mutation, no file write.
<!-- END:acceptance-criteria -->
