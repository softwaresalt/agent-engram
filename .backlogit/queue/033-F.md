Follow-up enhancements to the SQL parser (034-F) shipped in the tree-sitter-sequel 0.3 integration. Three improvement areas identified in the 034-F closure artifact:

1. **CREATE PROCEDURE grammar support** — blocked on upstream tree-sitter-sequel grammar producing ERROR nodes for CREATE PROCEDURE. Deferred until a grammar update lands.
2. **FROM reference resolution** — currently emits References edges with raw identifier strings; should resolve to indexed table Class nodes in the workspace graph.
3. **Multi-schema reference support** — `schema.table` syntax (e.g., `FROM public.users`) not yet parsed; only simple identifiers extracted.
