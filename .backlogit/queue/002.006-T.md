## Description

Wire the backlog indexer into `ingest_all_sources` content-type dispatch
and extend query-path read surfaces so that backlog data ingested into
`backlog_content_record` is visible through `query_memory`, `query_graph`,
and `unified_search`.

## Scope

- `src/services/ingestion.rs` (add branch for `content_type == "backlog"`)
- `src/services/code_graph.rs` or query-path module (extend `query_graph` to traverse `backlog_edge`)
- `src/services/memory.rs` or equivalent (extend `query_memory` / `select_content_records` to union `backlog_content_record`)
- `src/services/search.rs` or equivalent (extend `unified_search` to include `backlog_content_record` results)

## Implementation

- In `ingest_all_sources`, add: `if source.content_type == "backlog" { ... }`
- Call `index_backlog_source` + `sweep_deleted_backlog_files`
- Return indexer summary counts in `IngestionSummary`
- Hash-based incremental sync is handled internally by the indexer (Unit 4)
- Extend `query_graph` execution to traverse `backlog_edge` when the relation exists
- Extend `query_memory` to union results from `backlog_content_record` when content_type is "backlog" or "all"
- Extend `unified_search` to include `backlog_content_record` in its result set (same pattern as generic `content_record`)

## Tests

- `tests/integration/backlog_hydration_test.rs` (5 scenarios):
  workspace with registry declaring backlog source; verify nodes in DB after
  ingest; verify deletion sweep works; verify `query_memory` returns backlog
  content; verify `query_graph` traverses backlog edges; verify `unified_search`
  includes backlog results; 100-item performance assertion (< 5s)

## Acceptance Criteria

- `ingest_all_sources` processes backlog sources alongside other content types
- Backlog nodes appear in DB after ingestion
- `query_memory` returns backlog content records when queried
- `query_graph` traverses `backlog_edge` relations
- `unified_search` includes backlog content in search results
- Performance: 100+ items indexed in < 5 seconds
- `cargo test` passes
