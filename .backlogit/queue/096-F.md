Extend engram's Rust-built canonical-path call resolution (091-F) to Python's module namespace so cross-module same-name calls resolve to the correct target instead of being dropped by name-only ambiguity. Layers on 094-F Python Calls extraction. Stash FE8B3B2D; **feature/spike fork "Option B" ratified** (product value operator-asserted; feasibility spike = GO). NOTE (F19 naming disambiguation): this feature-level "Option B" is the product/spike fork and is DISTINCT from the plan's implementation-level "Option A" (the bare-call-routing fork = provenance staging over the canonical post-pass); the two "Option" labels live in different decision namespaces and do not conflict.

<!-- BEGIN:description -->
Python modules ARE namespaces (foo/bar.py -> foo.bar). This feature adds a Python analogue of the Rust canonical machinery: (1) Python module-path + import-binding capture, (2) a Python function_meta.canonical_path populator, (3) a Python-aware canonical resolver branch that reuses the existing singleton/duplicate fail-closed core (function_ids_by_canonical_path) with ZERO DB/schema change.

Resolution rule (frozen, last-binding-wins per Python module scope): bare call -> a LATER `from N import name` that rebinds over a local def WINS -> N.name (import-rebind precedence, X2/X3); else defined-in-module M (not shadowed by a later import) -> M.name; else imported via `from N import name` -> N.name; else `mod.name()` with mod a bound module -> <mod>.name; else (star/relative/package-root/re-export/dynamic/unbound/local-shadow/unclear-order) -> DROP.

Scope FROZEN: IN = module-level functions + module.func() disambiguation. OUT (documented non-goal) = instance-method dispatch (self.method()/obj.method()), which needs type inference. Related bug FF7DE872 (same-file same-name shadowing) is SPLIT OUT and INDEPENDENT — NOT subsumed here (the canonical index fails closed on the duplicate canonical_path rather than applying last-wins).

Independent of shipment 090-S / 095-F (operator-ratified: no blocking dependency). Sequences after 094-F (merged).
