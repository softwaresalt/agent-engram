## Scope

Create `src/cli/commands/indexing.rs` with 2 handlers:

| CLI Command | MCP Method | Params |
|---|---|---|
| `engram sync` | `sync_workspace` | `{}` |
| `engram sync --full` / `engram index` | `index_workspace` | `{}` |

`engram index` is an alias for `engram sync --full`. Both route to `index_workspace`.

Note: `index-git` (method `index_git_history`) is excluded from default scope because
it is feature-gated behind `git-graph`. It will be added when that feature ships.

These are the primary commands for start.ps1 preloading.

## Acceptance Criteria

- `engram sync` sends IpcRequest with method `sync_workspace`
- `engram sync --full` sends IpcRequest with method `index_workspace`
- `engram index` sends IpcRequest with method `index_workspace`
- Contract tests verify request construction including --full flag logic
