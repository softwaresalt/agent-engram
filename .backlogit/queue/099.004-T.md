rust-reviewer P1-760 (deferred; v1 recall non-goal Y1). Function-local imports are currently reduced to a boolean "poison" flag and never call ImportBindings::resolve_call. The bindings module already supports richer symbol-level resolution than the production path exercises. Resolving provable function-local imports would improve recall without weakening the fail-closed invariant.

<!-- BEGIN:acceptance-criteria -->
- A provable function-local `import x` / `from m import f` resolves its calls to the exact target.
- Ambiguous/rebound function-local cases still fail closed (no false edges).
- Acceptance corpus extended with a function-local positive + adversarial case.
<!-- END:acceptance-criteria -->

<!-- BEGIN:implementation-notes -->
Route function-local bindings through ImportBindings::resolve_call (bindings.rs) instead of the boolean poison in the module-qualifier/bare path. Preserve fail-closed on any rebind/shadow.
