Deferred Copilot finding (PR #255 cycle 8, `code_graph.rs:188`; single reviewer, P2, missing-edge class). Unit B never applies the A4 `ReexportMap` (built in the canonical context but currently dead — no production consumer) before matching a call's resolved canonical path against `function_meta.canonical_path`. A call routed through a facade re-export — `pub use crate::a::helper;` then `crate::facade::helper()` — resolves to the facade path `crate::facade::helper`, but the definition is keyed under its defining path `crate::a::helper`, so the two never match and NO edge is produced.

Blast radius is bounded by the fail-closed invariant: this is a MISSING-edge (never a false edge), self-healing on the next full index once the re-export map is wired in. It is deliberately out of scope for the 088-S cycle-8 fix set (which prioritizes eliminating FALSE edges); flipping on re-export canonicalization is a substantial feature that must be adversarially reviewed on its own. Scope for a fix: (1) thread the A4 `ReexportMap` into the canonical match step so a facade path is rewritten to its defining path before lookup, (2) preserve the exactly-one-target precision gate (a re-export that fans out to multiple definitions must still fail closed), (3) add regression fixtures asserting an edge IS produced for a `pub use` facade call and NO edge for an ambiguous fan-out re-export. Low priority: adversarial-only, single-reviewer, missing-edge (safe direction).
