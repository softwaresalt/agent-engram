Plan unit F09 - existing-generation open via database-owned runtime copy. Implement the open strategy selected by F01 in `src/db/cozo_backend/mod.rs`, exposed through store-minted `OpenedGeneration` / `RuntimeCopy` values.

If Cozo cannot provide a proven read-only open of an existing database, the daemon copies the sealed generation into a generation-specific private runtime directory under `.engram/generations/runtime` and opens that copy instead. The published generation is never modified, and request pinning applies to the opened private copy.

Execution posture: test-first.

<!-- BEGIN:acceptance-criteria -->
- The open path is exactly the strategy F01 proved: read-only open, or private runtime copy.
- The published generation is never mutated by an open.
- Runtime copies live under `.engram/generations/runtime` and are created with bounded temp-plus-seal publication.
- `OpenedGeneration` and `RuntimeCopy` can be minted only by the store.
- Runtime copies are retained and observable in this release; nothing is deleted.
- This unit defines only `ExistingDbLocation` and the open strategy; it does NOT import generation-service types.
- `tests/integration/generation_db_open_test.rs` covers both open paths and non-mutation of the published generation.
<!-- END:acceptance-criteria -->
