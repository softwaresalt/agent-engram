Implement ignore-never-promote handling for orphaned temporary files left behind by an interrupted publication. A stale temporary must never be mistaken for a publishable candidate or promoted to active.

<!-- BEGIN:acceptance-criteria -->
- Orphaned temporaries are detected and ignored.
- No code path promotes a temporary file to the active manifest.
- Ignoring an orphan is non-destructive: this unit does not delete generations (deletion is out of scope for the whole feature).
- Presence of an orphan does not block a subsequent valid publication.
<!-- END:acceptance-criteria -->
