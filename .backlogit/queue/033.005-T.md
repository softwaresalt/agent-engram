# Add CREATE PROCEDURE Support to SQL Parser

## Description

Extend the SQL parser (`src/services/parsing/sql.rs`) to extract symbol
definitions from `CREATE PROCEDURE`, `CREATE FUNCTION`, and similar DDL
statements. Currently only `CREATE TABLE`, `CREATE VIEW`, and `CREATE INDEX`
are handled.

Source: stash `19D78639` — "SQL parser: CREATE PROCEDURE, FUNCTION DDL support"

## Scope

- `src/services/parsing/sql.rs` — add DDL extraction for PROCEDURE/FUNCTION nodes
- `tests/unit/parsing_test.rs` — add unit tests for extracted symbols

## Blocker

**Blocked on upstream grammar**: `tree-sitter-sequel 0.3` does not yet parse
`CREATE PROCEDURE` statements. The grammar defines `create_procedure_statement`
as a placeholder node only. This task becomes unblocked when a tree-sitter-sequel
release adds full PROCEDURE/FUNCTION grammar support.

Track: https://github.com/nickel-lang/tree-sitter-sequel/issues (check for
PROCEDURE grammar update).

## Acceptance Criteria

- `extract_create_references` handles `create_procedure_statement` and
  `create_function_statement` nodes
- Extracted symbols appear as `class` nodes in the code graph
- Unit tests for `CREATE PROCEDURE foo()` and `CREATE FUNCTION bar() RETURNS INT`
- `cargo test` passes

## Notes

Do not implement until tree-sitter-sequel provides a working grammar for
PROCEDURE/FUNCTION. The old task ID 033.003-T was retired to avoid collision with
the archived repo-config task under 033-C (`.backlogit/archive/033.003-T.md`).
