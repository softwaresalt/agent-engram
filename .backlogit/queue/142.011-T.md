Plan unit F06 - generation module and domain types. Create the private `src/services/generations/` module with `mod.rs` and `manifest.rs`, defining the generation domain: strict single-component generation IDs, a checked monotonic revision, branch and workspace identity, the sealed inventory, per-file digests, and provenance.

The module is private. It exposes only the minimal safe public facade the separate `engram-indexer` crate requires; implementation details and constructors stay crate-private.

Execution posture: test-first.

<!-- BEGIN:acceptance-criteria -->
- Generation IDs are strict single-component values; path separators and traversal segments are rejected at construction.
- Revision is a checked monotonic type; a non-increasing revision is a typed error.
- The manifest carries generation identity, schema version, branch identity, workspace identity, inventory and digests.
- Provenance fields are present on the manifest.
- The module is private; only the minimal supervisor facade is public.
- `tests/unit/generation_domain_test.rs` covers ID rejection, revision checking, and manifest round-trip.
<!-- END:acceptance-criteria -->
