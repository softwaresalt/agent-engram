Plan unit F10 - candidate indexing service. Change `src/services/code_graph.rs` to accept only a sealed `IndexTarget` minted by the F07 store, and never an arbitrary caller-supplied path. This is what makes it structurally impossible for indexing to write into the generation currently serving reads.

Execution posture: test-first.

<!-- BEGIN:acceptance-criteria -->
- The indexing entry point accepts only a sealed `IndexTarget`.
- No public path exists that accepts a raw filesystem path for indexing.
- `IndexTarget::LegacyDirect` preserves current managed-mode indexing behavior.
- `IndexTarget::Candidate` writes only into an exclusive candidate directory.
- Indexing never writes into the active generation.
- `tests/integration/candidate_indexing_service_test.rs` covers both target kinds and asserts the active generation is untouched.
<!-- END:acceptance-criteria -->
