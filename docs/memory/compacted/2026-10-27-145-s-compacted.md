## Decisions

* `mint_generation_id` keeps `GenerationIdError`: the plan's closed variant list
  has no fitting variant (stash `30B6579E`, related to `26CD3785`).
* Reserved-ID check is ASCII case-insensitive for case-insensitive file systems.
* A missing `cozo/` directory maps to `DatabaseNotFound { count: 0 }`.
* Post-seal failure leaves the partial candidate directory (stash `2E381AFD`).
* Copilot review findings deferred under P-021 C1: `IndexResult.errors` handling
  (stash `F03AAA77`) and streaming SHA-256 (stash `420048FC`).

## Learnings

* A live engram daemon locks `target\debug\engram.exe`; build with a separate
  `CARGO_TARGET_DIR` (`target-145`).
* `integration_backlog_hydration` (5 s timing) and `integration_markdown_indexing`
  (cozo lock panic) are load-sensitive and passed on rerun.
* After switching branches the daemon can stay un-Ready for many minutes while
  hydrating; post-merge `engram` CLI probes then time out.
