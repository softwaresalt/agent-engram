# Completed release-unit memory compaction

## 083-S — PowerBI/DAX followups (087-F)

PR #257 (merge `e0f8e440`) centralized source traversal into a
symlink-cycle-safe helper (`is_regular_file_in_workspace`) shared by the
PowerBI, PBIP, notebook, and backlog indexers, with matching symlink-safe
deletion sweeps; folded a `TMDL_DAX_INDEX_VERSION` namespace into the
persisted TMDL hash to force one-time re-index on bump; tokenized DAX `--`
comments so references inside them stop emitting findings. Four Copilot
cycles progressively found and fixed collector-vs-sweep symlink asymmetry
and a `has_root()` validator gap. Two architectural findings were
deliberately deferred rather than rushed: `087.005-T` (stale alias-backed
records need collected-set reconciliation) and `087.006-T` (per-record TMDL
write exposes hash before completion — confirms a pre-PR P2 deferral).

## 084-S — Durable staged_call provenance (089-F)

PR #253 (merge `a0962f6`) closed a durability gap where staged cross-file
calls were lost across daemon dehydrate/rehydrate: `staged_call` now exports
to `staged_calls.jsonl` on dehydration and rehydrates on restart
(`SCHEMA_VERSION` 5.0.0→5.1.0, generation-gated sidecar, fail-closed against
mixed-generation writes). Scope was locked to the existing 4 columns; marker
fields (`is_method`, `is_qualified`, `provenance`) were deferred to 088-S
Unit B via a forward-compatible (`#[serde(default)]`) JSONL format. Existing
5.0.0 workspaces need `engram update`/`reinstall` to activate durable
staging.

## 085-S — CLI↔MCP parity (090-F)

PR #259 (merge `945ece65`) shipped a docs-and-test-only parity audit: a
canonical mapping doc (`docs/cli-mcp-parity.md`), a drift-guard contract
test derived from the real dispatch `match` (not a hand-maintained mirror),
and bidirectional doc references. Adversarial review ran before Copilot per
operator directive to minimize iteration count. `090.004-T` (functional gap
closure) stayed blocked pending a follow-on audit-derived shipment;
`090.005-T` (routing-identity registry) was queued from Copilot findings.

## 087-S — Option C Unit A: canonical-identity infrastructure (091-F)

PR #251 (merge `d5ef75b`) landed precision-neutral (0 new call edges),
fail-closed canonical-identity infrastructure (module-path/use-graph
plumbing honoring `[workspace].exclude`). The originally planned A8 "forced
re-index" step was removed: symbol IDs are random UUIDs, so re-parsing
unchanged files would disturb the edge set — canonical_path ships
additive/opportunistic instead, with ID-preserving backfill deferred to
Unit B. Merged over a red non-required `build` check after 3 identical
failures confirmed the HF-embeddings-download flake was environmental
(circuit-breaker: stop re-running, proceed).

## 088-S — Option C Unit B: canonical call-edge resolution (091-F)

PR #255 (merge `0d4821e`) enabled precision-gated `calls_resolved_canonical`
edges (edges emitted only on exactly-one non-empty canonical-path
resolution; ambiguity/shadowing drops the edge). Nine adversarial/Copilot
cycles fixed generic-type-parameter shadowing, nested `#[path]` recursion,
extern-crate alias rebinding (`C8-5`), and Cargo dependency-rename shadowing
(`C9-1`) — all fail-closed. Incremental `sync_workspace` intentionally skips
the expensive canonical post-pass and sweeps stale canonical edges instead,
preserving precision over recall between full indexes. Three low-priority
recall/observability follow-ups (`091.017-T`, `091.019-T`, `091.020-T`)
queued, none blocking.

## Common threads

All five shipments share the same known external flakes (HF-embeddings CI
download timing; occasional CozoDB connect flake) — environmental, not
code, and repeatedly confirmed by isolated re-runs. PR #248 (081-S,
superseded by Option C) remained open throughout for operator disposition.
