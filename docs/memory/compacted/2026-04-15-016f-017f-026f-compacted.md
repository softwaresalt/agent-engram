## Critical Technical Findings (permanent reference)

### Grammar ABI Constraint
`tree-sitter 0.24.x` accepts ABI 13–14 only. Grammar crates v0.23.x emit ABI 14 ✓;
v0.24+ emit ABI 15 ✗ (runtime failure, not compile-time). **Pin all grammar crates to `"0.23"`.**
Full detail: `docs/compound/build-errors/tree-sitter-grammar-abi-tsx-dispatch-2026-04-15.md`

### TSX vs TypeScript Grammar
`.tsx` files require `LANGUAGE_TSX`; `.ts` files use `LANGUAGE_TYPESCRIPT`. Using the wrong grammar
silently mis-parses JSX nodes. `Language::Tsx` is a distinct enum variant dispatching to `parse_tsx_source()`.

### Windows Path Normalization
`canonicalize` returns `\\?\C:\...`; `canonicalize_workspace` strips this prefix. Tests must use
`engram::db::workspace::canonicalize_workspace()` not `std::fs::canonicalize` for path comparisons.

### Local Full-Suite Stall on Windows
After `cargo test --test X` compiles ort-sys, `cargo test` (full suite) may hang on Windows with
zero output. Push to CI (Linux) instead — completes in ~3.5 min using cargo cache.

### Flaky Timing Test
`t020_s001_s005_daemon_becomes_healthy_within_2_seconds` passes in ~1.33s isolated, fails at ~11.82s
under parallel test load. Pre-existing; not related to 026-F.
