## Decisions

* Harness-first (`7bc9a17f`, 3 RED tests with `Worker: 142.070-T`), implementation `32265c68`, review fixes `372ea2ce`.
* `deadline_from` adds a `MAX_TIMEOUT_MS` cap (`u32::MAX` seconds) because `Instant::checked_add` does not overflow for
  `u64::MAX` ms on Windows; the cap is documented in rustdoc and covered by a boundary test.
* `cause=deadline` is classified after `run` returns (`Instant::now() >= deadline`); `make` always runs before a
  zero-timeout failure, so a zero timeout with a failing factory reports `cause=setup`.
* Four-persona local review: no P0/P1; in-scope P2/P3 fixed. Copilot review: no findings. No P-021 stash entries.
