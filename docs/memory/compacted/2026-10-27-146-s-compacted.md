## Outcome

Shipment 146-S delivered `open_generation_store`, `current_published_revision`,
`publish_sealed_candidate` and the private `within_root` comparator in
`src/services/generations/candidate_build.rs`, plus the visibility-only change to
`read_current_manifest_revision` in `publish.rs`. Feature PR #423 merged with a merge
commit `878c5eedb4c15f29e50cf44840aed30e15991c06`.

## Decisions

* Copilot found that `create_dir_all` ran before the containment check, so a mutated
  public `generations_root` could create a directory outside the workspace. Classified
  in scope (P-021 C1: completes the authorized containment contract) and fixed in
  `e4f97ba0` with `validate_store_destination` (no `..`, deepest existing ancestor
  unlinked and inside the workspace via `within_root`), plus a regression in scenario 2.
* `within_root` stayed the only `Path::starts_with` in `candidate_build.rs`.

## Learnings

* `ReadServerLayout` fields are public: any function that creates paths from them must
  validate the destination before creation, not only after.
* `cargo dev-test` had one load-related flake (`hcl_indexing_test` cold start) that passed
  on rerun.
* After a branch switch the daemon stayed `starting` even after the `set_workspace`
  re-latch; runtime probes were blocked (stash `6B3DD712`).
