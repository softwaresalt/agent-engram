## Outcome

Shipment 156-S delivered `142.054-T` (F50c), closing the F50 family: the four probe stages of `ProductionVerifier`
(`DaemonVerified`, `HealthVerified`, `CliProbeVerified`, `McpProbeVerified`) in `crates/engram-indexer/src/preflight.rs`
and real-chain cases in `tests/integration/preflight_gate_test.rs`, under Dark Mode (P-017). Feature PR #443 merged at
`f11590bf0fd2609baf4a358a96fee919b506e70f`. `142.054-T` was moved to `done` and archived with the official CLI.

## Decisions

* Probe stages are observational only (R48): they wait for request-entry reconciliation through the existing
  `engram::preflight_probe` facades; no generation-control endpoint is called.
* `DaemonVerified` maps a never-observed expected generation (`ProbeError::Mismatch`) to the typed deadline-expired kind.
* The CLI data fingerprint is held on the verifier and compared by the MCP stage; a missing fingerprint fails closed.
* Real-chain tests spawn a real read-server or managed daemon with a finite idle timeout and fail fast if it exits;
  a compiled fake-engram fixture covers mismatched and missing MCP fingerprints (Copilot finding).
* Deferred (P-021 C2) stash entries: `D58542C8` (probe children should clear ENGRAM_* env), `170800D5` (duplicate of
  `1AB175A8`: `Preflight::verify` discards verifier reasons).

## Environment notes

* Builds used `CARGO_INCREMENTAL=0` and `CARGO_PROFILE_DEV_DEBUG=0`.
