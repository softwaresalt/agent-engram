## Key Decisions

- **pulldown-cmark 0.10 over tree-sitter-md**: tree-sitter-md had ABI uncertainty; pulldown-cmark was already a dep with a stable `into_offset_iter()` event API
- **Markdown symbol model**: headings → `ExtractedClass`, fenced code blocks → `ExtractedFunction` (name = `codeblock-L{line}`), links → `ExtractedEdge::Imports`. Zero new enum variants, zero schema changes
- **SQL recommendation**: `tree-sitter-sequel 0.3.11` — requires `~0.25.0`, emits ABI 15, broadest dialect coverage. Build-verified.
- **`ExtractedEdge::Imports`** used for link edges (plan said `References`; implementation used `Imports` — functionally correct, existing variant)
