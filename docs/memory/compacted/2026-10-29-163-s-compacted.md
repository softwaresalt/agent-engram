## Outcome

Shipment 163-S delivered `142.055-T` (F51): `start.ps1` runs `target\debug\engram.exe preflight <WORKSPACE> --timeout-ms <T>` through `ProcessStartInfo.ArgumentList`, fails closed on any non-success, and kills only its own child. Feature PR #457 merged at `eb9e481406e76a9511a47592f1c5b600a2e607d6` under Dark Mode (P-017).

## Decisions

* The parked harness exceeded the 400-line SB-1(c) cap, so a compact 172-insertion harness with a rustc-built fixture `engram.exe` replaced it.
* Launch requires exit 0 and a `Succeeded` verdict line; `#Requires -Version 7.0` guards `ArgumentList`.
* Pipe output is captured per character by a background reader so partial diagnostics survive an unowned descendant holding the pipes.
