## Learnings

* The `engram --json workspace-status` output has `result.generation.active_revision` and
  `published_revision`, not the generation ID string; assert on those.
* `try_wait()` must run every owner-loop iteration, not only on receive timeouts, or a chatty grandchild
  hides the shim's exit (Copilot finding; regression fixture `mcpchatty`).
* `hcl_indexing_test` failed once in a full run under load and passes alone and on rerun.
