## Implementation Summary

Added two `AtomicU64` process-global statics to `src/db/cozo_queries.rs` for SQLITE_BUSY retry telemetry:
- `MUTABLE_RETRY_COUNT` — increments on each retry after the first attempt
- `MUTABLE_LAST_RETRY_EPOCH_MS` — records Unix ms timestamp of most recent retry

Exposed via new `get_mutable_script_retry_metrics` MCP tool (no workspace binding required). Tool returns `{ retry_count: u64, last_retry_at: string|null }`.
