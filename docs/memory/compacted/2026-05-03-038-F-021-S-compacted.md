## Key Decisions

1. **Unit 4 retry granularity**: Top-level `run_with_busy_retry` wrapping `index_workspace_impl` is unsafe — `upsert_code_file` commits `content_hash` before symbol upserts complete. A SQLITE_BUSY mid-symbol causes the retry to skip the file as "already indexed", leaving permanent partial rows. Fix: `run_script_busy_retry_mutable` private method (5 attempts, 50–500 ms exp back-off) applied at each individual `run_script(Mutable)` call.

2. **Unit 1 fallback**: `dehydrate_code_graph` detects partial writes by comparing `count_functions()` (meta count) vs `all_functions()` (INNER JOIN count). Discrepancy fills missing symbols from `all_function_metas()` before writing `nodes.jsonl`.

3. **Copilot review finding was valid** — addressed in `d727183`, reply posted, thread resolved via GraphQL.
