Shipment **005-S** shipped. Merge SHA `0dd956f`. Feature `027-F` + 11 tasks archived.
Swift, C, and C++ parsers implemented; Kotlin deferred (ABI incompatibility).

## Key Decisions

| Decision | Rationale |
|---|---|
| Option B (not A/C) | Ship compiled-language pack now; defer SQL/Markdown until IR extension lands during CozoDB migration |
| tree-sitter 0.24 → 0.25 | `tree-sitter-swift 0.7.1` emits ABI 15; 0.25 runtime accepts 13–15; backward-compatible with 0.23.x grammars |
| Kotlin deferred | `tree-sitter-kotlin 0.3.x` targets ts 0.20–0.22; type-incompatible with ≥0.24; stub returns empty ParseResult |
| No-op stubs (not Err) | P1 plan-review fix: stubs return `Ok(ParseResult::empty())` so mixed-lang workspaces don't break between SI-1 and sub-epics |
| bare `struct_specifier` / `class_specifier` arms | C: `struct Point {};` is parsed as bare `struct_specifier` under `translation_unit`, not inside `declaration`. Same pattern in C++. |
| `#[allow(clippy::unnecessary_wraps)]` on `parse_kotlin_source` | Dispatcher requires `Result<ParseResult, _>` signature; stub never errors — suppress pedantic lint |
