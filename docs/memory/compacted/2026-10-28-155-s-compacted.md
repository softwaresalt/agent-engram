## Decisions

* The verifier owns a current-thread runtime, refuses to nest (at construction and at Build) and shuts the runtime
  down in the background on drop so it can be dropped inside async code.
* Deadline in force is the earlier of the machine's and the constructor's. Typed expiry is the additive
  `VerificationErrorKind::DeadlineExpired`; `Failure` is unchanged.
* Seal and Publish are bound to the one expected generation. Probe stages stay unimplemented for Slot-09c.
* The F50b tests live in a `cozo-backend`-gated module (Copilot finding) so the F50a tests stay backend-independent.
* Deferred (P-021 C2) stash entries: `16172B49`, `1AB175A8`, `3CF808CD`, `8ECFE00E`, and `8D20C81B` (Copilot thread
  `PRRT_kwDORJEduc6xJzgO`, post-rename durability-uncertain publish outcome).
