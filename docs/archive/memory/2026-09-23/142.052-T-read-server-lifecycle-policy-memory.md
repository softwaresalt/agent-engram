## Summary

Implemented the read-server lifecycle policy so read-server startup skips managed hydration, offline scan, watcher registration, implicit sync, and shutdown flush while managed mode keeps the existing lifecycle path.

## Files modified

* `src/daemon/lifecycle_policy.rs`
* `src/daemon/startup_activation.rs`
* `src/daemon/watcher.rs`
* `src/tools/lifecycle.rs`
* `tests/integration/read_server_lifecycle_test.rs`

## Decisions

* Added lifecycle activity counters in `lifecycle_policy.rs` so the integration test can assert direct absence/presence of each activity without timing proxies
* Routed read-server startup through a cheap binding publication path that publishes workspace identity/config and starts TTL without calling managed hydration
* Kept watcher policy out of `ipc_server.rs` by making `watcher.rs` re-resolve daemon mode and delegate the allow/skip decision to `lifecycle_policy.rs`
* Skipped shutdown graph flush in read-server mode while preserving metrics shutdown
