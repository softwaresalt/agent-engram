# Operational Closure: 010-S — Backlogit Ship-Shipment Integrity

## Summary of Change

Shipment 010-S delivered the `pre-archived` classification spec gap fix for
the `shipment-reconcile` skill. This addresses the scenario where a manifest
item was archived by a previous shipment before the current shipment runs its
pre-ship gate — previously such items would cause a `HALT` (false negative).

**Items shipped:**
- `032-F` — feat(skills): add `pre-archived` classification to SKILL.md and schema
- `032.001-T` — dogfood reconcile gates during this shipment (intake + pre-ship reports produced)
- `032.002-T` — file upstream issue with backlogit maintainers (`softwaresalt/backlogit#63`)

## Invariants to Preserve

- `shipment-reconcile` must still gate on all `missing`, `status-mismatch`, and `orphan` items
- `pre-archived` must remain a DISTINCT classification from `matched` — items are visible in the report
- The `PROCEED` outcome for `pre-archived` must only apply when archive file actually exists
- `expected_status: active` is only valid at intake (Step 0.5), never at pre-ship gate (Step 6)
- Post-mode `matched` semantics (archive-present) must not bleed into pre-mode behavior
