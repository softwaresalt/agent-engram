# Operational Closure — 005-S Compiled Language Parsers (Pre-Merge)

## Change Summary

Adds tree-sitter parsing support for Swift, C, and C++ to the engram code-graph
indexing service (feature 027-F, Group B compiled languages). Upgrades the
tree-sitter runtime from 0.24 to 0.25 to accept grammar ABI 15 (required by
`tree-sitter-swift 0.7.1`). Kotlin is stubbed and deferred — no crates.io release
is compatible with tree-sitter ≥0.24.

3. C structs declared without a variable declarator (`struct Point { ... };`) are extracted.
4. C++ classes/structs declared without a declarator are extracted.
5. Swift ABI 15 grammar loads without panic on first `set_language()` call.

## Rollback Trigger

**Trigger**: Daemon emits `Incompatible language version N` (ABI mismatch panic) on startup after merge, OR parser unit tests fail on main.

## Rollback Procedure

1. Revert the `tree-sitter = "0.25"` line in `Cargo.toml` to `"0.24"` and revert `tree-sitter-swift = "=0.7.1"` removal — this returns all grammar crates to ABI 14.
2. If Swift support is still desired, investigate which `tree-sitter-swift` version emits ABI ≤14 and pin to that.
3. `cargo build && cargo test` to confirm recovery.

**Owner**: Merge author / next developer to index a compiled-language project.
